# Maps 1–12 EarlyWar Design Spec

Design framework and node-level specifications for maps 1–12, Complexity C
(Early War) only. Higher difficulties (B/A) share the same node layout with
scaled enemy fleets and stricter branch thresholds.

## Map complexity tiers

| Stars | Tier | Nodes | Patterns |
|-------|------|-------|----------|
| 1 | Simple | 3–4 | L |
| 2 | Simple | 4–6 | F |
| 3 | Medium | 7–9 | D, E |
| 4 | Heavy | 9–11 | M, N |
| 5 | Elite | 10–12 | S |

## Branching rule archetypes

| ID | Name | Condition |
|----|------|-----------|
| A | Always forward | `return nextNodes[1]` |
| B | Screen check | `capitalness.screens / capitalness.total >= threshold` |
| C | Capital avoidance | `capitalness.capital / capitalness.total <= threshold` |
| H | Capital preference | `capitalness.capital / capitalness.total >= threshold` |
| D | LOS gate | `los >= threshold` |
| E | Speed gate | `maxSpeed >= threshold or avgSpeed >= threshold` |
| F | Fleet type | `fleetType == CARRIER/SURFACE/NORMAL` |

## Enemy scaling by star tier (EarlyWar, tech ≤ 1935)

| Star | Mid-node enemy | Boss enemy | Note |
|------|---------------|------------|------|
| 1 | 2× DD | 3× DD + 1× CL | Minimal |
| 2 | 2× DD + 1× CL | 3× DD + 1× CA | Light |
| 3 | 3× DD + 1× CL + 1× CA | 3× DD + 2× CA or 3× DD + 1× CA + 1× BB | Standard |
| 4 | 3× DD + 1× CL + 1× CA | 4× DD + 1× CA + 1× BB | Heavy |
| 5 | 4× DD + 2× CL/CA | 4× DD + 2× CA + 1× BB | Elite |

Sub-route nodes use one tier lower than the map star level.
Expedition-end nodes use the same tier as mid-map nodes.
Enemy ship IDs are base-tier variants (no "Flagship" suffix).

## Common fields

All maps set:
- `lb_distance = 99` (no land-based air in EarlyWar)
- `exec` returns `false` (unused)
- `droptable` and `raredroptable` are `{}` (drop tables deferred)

## Map-level fields

All maps set `gauge = 0` and `softfactor = 20000`.
`starting_nodes = {1}` for all maps.
Map-level `branch_rule` returns the first starting node (always returns `1`).

## Enemy ship IDs

Exact ship IDs are drawn from `shipRegistry` filtered by `Tech ≤ starCap`.
For the pilot batch, reference IDs based on typical base-tier ships (verify against `doc/ships.csv`):

| Type | Tech | Example IDs |
|------|------|-------------|
| DD (destroyer) | 1924 | 0x7F010100, 0x7F011100 |
| CL (light cruiser) | 1924–1930 | 0x7F020100, 0x7F020200 |
| CA (heavy cruiser) | 1928–1933 | 0x7F030100, 0x7F030200 |
| BB (battleship) | 1924–1935 | 0x7B050100, 0x7B050200 |
| SS (submarine) | 1933–1935 | TBD from registry |

These are placeholders; actual IDs must be confirmed against `shipRegistry` at implementation time.
