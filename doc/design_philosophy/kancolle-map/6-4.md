# Kantai Collection Map 6-4 Design Philosophy
**Operation Island Re‑Conquest** (離島再攻略作戦)

## Map Overview
- **Purpose**: Test medium‑sized fleet composition with strict battleship/carrier limits; emphasizes air‑raid attrition and dynamic enemy scaling
- **Difficulty**: ☆☆☆☆☆☆☆☆☆ (9 stars), very high
- **Unlock Requirements**: Likely requires 6‑3 clear (Operation K)
- **HP Gauge**: Boss flagship sink reduces gauge by ⅕ (20%); 5 sinks required to clear
- **Unique Drop**: **秋津洲 (Akitsushima)** – only obtainable here, not buildable
- **Fleet Restrictions**: **Battleships <3 AND Carriers <3** (戦艦3隻以上、空母3隻以上は出撃不可)
- **Land‑Based Air Support (LBAS)**: Usable (1 squadron), no enemy air raids on base
  - Required radius to boss: **5** (reduced to **2** if equipped with 橘花改 or 噴式景雲改 jets)
  - Radius calculation starts from left‑side start point; attacking nodes right of boss requires up to radius 8
- **Historical Context**: Simulates re‑capture of a strategic island (Peacock Island) with mixed surface/air forces
- **Dynamic Enemy Scaling**: Enemy compositions strengthen based on **player HQ level** and **HP gauge remaining**
- **Post‑Clear Behavior**: After gauge destruction, boss node appears randomly (both pre‑ and final‑form patterns possible)

## Routing Rules
**Key Branching Conditions**:

### Start → A/B/M
- **To M** (submarine node) if ANY of:
  - Fleet contains **Landing Ship** (揚陸艦)
  - Fleet contains **Carrier‑type** (空母系)
  - Fleet contains **2+ Battleship‑type** (戦艦級) except **長門改二+陸奥改二 pair**
  - Fleet contains **3+ Aviation Cruisers** (航巡)
- **To B** if **high‑speed unified** AND either:
  - **Light Cruiser flagship AND 3 destroyers**
  - **4+ destroyers**
- **To A** if **2+ destroyers** (default for destroyer‑heavy compositions)
- **Otherwise M** (submarine node)

### A → D/E
- **To D** if **秋津洲 (Akitsushima) included** AND any of:
  - Exactly **1 Aviation Cruiser** (航巡)
  - **1+ Light Cruiser**
  - **3+ destroyers**
- **To E** if fleet contains **Battleship‑type** (戦艦級)
- **To E** if fleet contains **slow ship** (低速艦)
- **To D** if **Light Cruiser flagship**
- **To D** if **3+ destroyers**
- **Otherwise E**

## Design Patterns Observed
1. **Medium‑Fleet Focus**: Battleship/carrier limits (<3 each) prevent brute‑force solutions, encouraging balanced compositions
2. **Air‑Raid Attrition**: Four separate air‑raid nodes drain resources, teaching players to manage fuel/ammo reserves
3. **Dynamic Enemy Scaling**: Enemy strength tied to HQ level and HP gauge creates progressive difficulty; rewards early clearing
4. **Complex Routing**: Multiple conditional branches based on ship type, speed, and specific ships (秋津洲, 如月) demand careful fleet construction
5. **Submarine Resource Trap**: Node M consumes significant fuel (8%) with no ammo cost, punishing incorrect routing
6. **LBAS Radius Mechanics**: Special jet equipment reduces required radius (5→2), encouraging equipment optimization
7. **Carrier‑Battleship Hybrid Threats**: Nodes J/K combine high‑air‑power carriers with tough battleships, requiring combined‑arms response
8. **Post‑Clear Randomization**: Boss node after gauge clear mixes pre‑ and final‑form patterns, maintaining farming difficulty
9. **Unique‑Ship Routing**: 秋津洲 and 如月 affect branching, giving niche ships strategic value
10. **Pattern‑Weighted Boss**: Final boss patterns follow specific distribution (25% each for patterns 3‑5), not uniform random
