# Kantai Collection Map 1-5 Design Philosophy

## Map Overview
**World 1‑5: 鎮守府近海対潜哨戒 (Naval District Coastal Anti‑Submarine Patrol)** – The first **Extra Operation (EO)** map, introducing submarine enemies, HP‑gauge mechanics, monthly‑reset rewards, and dedicated anti‑submarine warfare.

### Purpose
- **Anti‑Submarine Warfare Tutorial**: First map where enemy submarines appear, teaching players how to fight underwater threats.
- **EO Introduction**: First “Extra Operation” map with HP gauge (4 boss‑flag‑ship sinks to clear) and monthly‑reset rewards (medal, special combat results).
- **Fleet‑Size Restriction**: Encourages small, specialized anti‑submarine fleets (4‑ship limit for optimal routing).
- **Resource‑Consumption Lesson**: Submarine‑combat nodes have reduced fuel/ammo consumption (8% fuel, 0% ammo), while boss node uses normal rates.

### Difficulty
- **Rank**: ☆☆☆☆☆ (Easy – but difficulty scales with HQ level)
- **Recommended Level**: Level 1‑30 destroyers/light cruisers with anti‑submarine equipment.
- **Resource Cost**: Low (fuel 8% per sub node, 20% at boss; ammo 0% at sub nodes, 20% at boss).
- **Repair Cost**: Minimal if proper anti‑submarine gear is equipped; risk of torpedo damage from elite submarines.
- **Special Mechanics**: HP gauge, monthly time limits, submarine‑specific combat rules.

### Unlock Requirements
- **Progression**: Unlocked after clearing 1‑4.
- **No special requirements**: Available to all players after 1‑4 completion.

### Node Details (Based on Kancolle Wiki)
1. **Node A: 敵偵察潜水艦 (Enemy Scout Submarines)**  
   - **Type**: Submarine combat node (always encountered)  
   - **Purpose**: First anti‑submarine battle; teaches submarine combat basics.  
   - **Resource Consumption**: Fuel 8%, ammo 0% (“submarine effect”).  
   - **Branch Point**: After A, fleet proceeds to Node C (branch point).

2. **Node B: 戦闘なし (No Combat)**  
   - **Type**: Non‑combat node (“気のせいだった”).  
   - **Purpose**: Random diversion; no resource cost.

3. **Node C: 敵通商破壊高速水上艦隊 A群 (Enemy Commerce‑Raiding Surface Fleet Group A)**  
   - **Type**: Surface combat node (light cruisers + destroyers).  
   - **Purpose**: Introduces surface combat in an anti‑submarine map; tests fleet’s ability to handle mixed threats.  
   - **Branch Point**: Determines route to D/E or H/I.

4. **Node D: 敵潜水艦隊 B群 (Enemy Submarine Fleet Group B)**  
   - **Type**: Submarine combat node.  
   - **Resource Consumption**: Fuel 8%, ammo 0%.  
   - **Branch Point**: After D, fleet proceeds to Node E (branch point).

5. **Node E: 敵潜水艦隊 C群 (Enemy Submarine Fleet Group C)**  
   - **Type**: Submarine combat node.  
   - **Resource Consumption**: Fuel 8%, ammo 0%.  
   - **Branch Point**: Decides between Node F (sub) or Node C (surface).

6. **Node F: 敵潜水艦隊 A群 (Enemy Submarine Fleet Group A)**  
   - **Type**: Submarine combat node.  
   - **Resource Consumption**: Fuel 8%, ammo 0%.  
   - **Progression**: Leads to Node G (no combat).

7. **Node G: 戦闘なし (No Combat)**  
   - **Type**: Non‑combat node (“敵影を見ず”).  
   - **Purpose**: Calm before boss branch.

8. **Node H: 敵通商破壊高速水上艦隊 B群 (Enemy Commerce‑Raiding Surface Fleet Group B)**  
   - **Type**: Surface combat node (same compositions as Node C).  
   - **Purpose**: Alternative surface combat path.  
   - **Branch Point**: Decides between Node I (carrier group) or Node J (boss).

9. **Node I: 敵侵攻機動部隊 (Enemy Invasion Task Force)**  
   - **Type**: Carrier‑group combat node (includes light/standard carriers).  
   - **Purpose**: Introduces air‑power mechanics in an EO map; tests anti‑air capability.  
   - **Air Power**: Enemy air power 23‑28 (requires 69‑84 for air superiority).  
   - **Progression**: Leads to Node G, then to boss branch.

10. **Node J: ボス 敵通商破壊主力潜水艦隊 (Boss – Enemy Commerce‑Raiding Main Submarine Fleet)**  
    - **Type**: Boss submarine combat node.  
    - **Purpose**: Map‑clear condition; HP‑gauge reduction (25% per flagship sink).  
    - **Resource Consumption**: Fuel 20%, ammo 20% (normal combat rates).  
    - **Progression**: Ends sortie after combat.

## Routing Rules

### Branching Conditions (Based on “ルート分岐法則” section)
Rules are evaluated top‑down; first matching condition applies.

| Branch Point | Destination | Condition |
|--------------|-------------|-----------|
| **C** → **B** | **J** (boss) | Fleet consists **only of coastal defense ships (海防艦)**. |
| | **J?** | **1 light cruiser + 4 coastal defense ships** (5‑ship fleet). |
| | **B** | Fleet **contains a submarine**. |
| | **Random** | Fleet **≤4 ships and contains a supply ship**. |
| | **B** | **All other cases**. |
| **J** → **D** → **E** | **E** | **1‑ship fleet**. |
| | **F** | **≥5 ships and contains a submarine**. |
| | **Random** | **≥5 ships and no submarine**. |
| | **E** | Fleet consists **only of coastal defense ships**. |
| | **E** | Fleet **contains a supply ship**. |
| | **F** | **All other cases**. |
| **F** → **E** → **C** | **C** | **≥5 ships**. |
| | **J** (boss) | Fleet consists **only of coastal defense ships**. |
| | **C** | **All other cases**. |
| **J** → **F** → **G** | **I** | Fleet **contains a battleship (高速戦艦 or (低速)戦艦)**, **standard carrier**, or **submarine**. |
| | **I** | Fleet **contains ≥2 light carriers**. |
| | **I** | Fleet **contains ≥3 light cruisers** (includes training cruisers, torpedo cruisers). |
| | **G** | **All other cases**. |
| **I** → **G** → **H** | **H** | **≥5 ships**. |
| | **J** (boss) | **All other cases**. |

**Notes on ship classification** (from wiki):
- “軽巡級” = light cruisers + training cruisers **+ torpedo cruisers**.
- “戦艦” includes both fast battleships (金剛‑class, Гангут, etc.) and slow battleships (扶桑‑class, 大和, etc.); internal data splits them but routing treats them the same.
- “補給艦” includes supply ships, special duty ships, lighthouse tenders, Antarctic observation ships, **escort carriers (特設護衛空母)**, icebreakers, etc.
- “海防艦” includes coastal defense ships and “海防戦艦” (not counted as battleships for routing).

### Design Intent
- **Small‑Fleet Emphasis**: Optimal routing (A→D→F→G→J) requires ≤4 ships, no battleships/carriers/submarines/supply ships, ≤2 light cruisers, ≤1 light carrier.
- **Anti‑Submarine Focus**: Submarine‑only nodes encourage dedicated anti‑submarine equipment.
- **Coastal‑Defense Niche**: Pure coastal‑defense fleets can go straight to boss (C→J) or take special routes.
- **Randomness Control**: Players can fix route by adhering to strict composition rules; deviations introduce randomness or force surface/carrier fights.

### Difficulty Progression
- **Enemy Tier**: Basic submarines → elite → flagship; surface ships (light cruisers, destroyers) → carriers.
- **EXP Values**: 30‑75 (A) → 40‑100 (D) → 60‑110 (E) → 70‑140 (F) → 100‑180 (C/H) → 100‑180 (I) → 160‑220 (J).
- **Formations**: Submarine nodes use 梯形 (diamond), surface nodes use 単縦 (line ahead), carrier node uses 輪形 (circular).
- **Threat Level**: Submarines deal opening torpedo strikes; carriers require air superiority; surface nodes add variety.

## Resource Nodes
No resource‑collection nodes in 1‑5. However, **submarine combat nodes (A, D, E, F)** have special resource consumption:
- **Fuel**: 8% (instead of normal combat consumption)
- **Ammo**: 0%

**Boss node J** uses normal combat rates (20% fuel, 20% ammo).

This teaches players that fighting submarines is less resource‑intensive than surface combat, encouraging anti‑submarine specialization.

- **EO‑Specific Rewards**: Medal and special combat results (monthly) provide long‑term goals.
- **Level‑Gated Drops**: 明石 drop restricted to HQ level 40+, adding a progression gate.

## Design Patterns Observed

### 1. Extra Operation (EO) Mechanics
- **HP Gauge**: Boss flagship sink reduces gauge by 25%; 4 sinks clear map.
- **Monthly Reset**: Gauge resets at beginning of month; special combat results (戦果) deadline: end‑of‑month 21:59; medal deadline: 23:59.
- **Rewards**: Clear reward = medal ×1 + special combat results +75.
- **Post‑Clear**: After deadline, logging out/in removes clear mark and restores gauge.

### 2. Anti‑Submarine Warfare Tutorial
- **Submarine‑Only Nodes**: Introduce submarine combat mechanics (opening torpedo, anti‑submarine equipment, formation bonuses).
- **Reduced Resource Cost**: Teaches that submarine battles are cheaper.
- **Formation Importance**: Single‑line formation forced for ≤3 ships; diamond formation best for anti‑submarine.
- **Night‑Battle Limitation**: Submarines cannot be sunk at night (percentage damage only).

### 3. Fleet Composition Restrictions
- **Small‑Fleet Emphasis**: Optimal routing requires ≤4 ships, no battleships/carriers/submarines/supply ships.
- **Coastal‑Defense Niche**: Pure coastal‑defense fleets get special routing (direct to boss).
- **Carrier/Battleship Penalty**: Including them forces harder routes (carrier group node I).
- **Supply‑Ship Randomness**: Supply ships introduce random routing, discouraging their use.

### 4. Progressive Difficulty Scaling
- **HQ‑Level Scaling**: Enemy patterns strengthen with HQ level (e.g., more elite submarines, flagship appearances).
- **Pattern Variety**: Multiple patterns per node ensure unpredictability.
- **Air‑Power Introduction**: Node I introduces carriers and air combat in an EO context.

### 5. Psychological Design
- **Controlled Randomness**: Players can fix route with strict composition, but deviations add risk.
- **Reward Visibility**: Clear medal reward and monthly reset create tangible goals.
- **Learning Through Specialization**: Teaches players to build dedicated anti‑submarine fleets.

## Implementation Notes for FleetMemories

### Adaptation Considerations
1. **EO System**: Implement HP‑gauge mechanics with monthly reset and medal rewards.
2. **Submarine Combat**: Add submarine‑specific rules (opening torpedo, anti‑submarine equipment, formation bonuses, reduced resource cost).
3. **Routing Complexity**: Implement branching conditions based on ship types/counts (coastal defense, submarines, supply ships, etc.).
4. **Air‑Power Integration**: Include air‑power calculations for carrier node I.
5. **HQ‑Level Scaling**: Optionally scale enemy patterns based on player level.

### Suggested FleetMemories Implementation Options

**Option 1: Simplified EO Tutorial** (Easier Implementation)
- **Node Count**: 5 nodes (Start → Sub → Surface → Sub → Boss).
- **Enemy Types**: Submarines only, with one surface node for variety.
- **Routing**: Fixed linear path; ignore complex branching.
- **HP Gauge**: Simple 4‑sink requirement; monthly reset.
- **Rewards**: Medal + special combat results.

**Option 2: Full Branching Emulation** (Closer to Kancolle)
- **Node Count**: 10 nodes (as per wiki layout).
- **Branching Rules**: Implement all conditions (ship type, count, submarine presence).
- **Enemy Variety**: All submarine/surface/carrier patterns.
- **Resource Consumption**: Different rates for submarine vs normal combat.
- **Air‑Power Mechanics**: Include air superiority for node I.

**Option 3: Hybrid Approach**
- **Deterministic First Clear**: Guaranteed boss route for first few sorties (tutorial).
- **Branching After Tutorial**: Introduce full branching after player has anti‑submarine equipment.
- **Adjustable Difficulty**: Let players choose between simple (≤4 ships) or complex (larger fleets) routing.

### Map Design Principles to Emulate
1. **Anti‑Submarine Focus**: Teach submarine combat mechanics through dedicated nodes.
2. **Small‑Fleet Encouragement**: Reward players for using light, specialized fleets.
3. **Monthly Progression**: Provide recurring goals with resetting HP gauge.
4. **Controlled Randomness**: Allow route fixing through strict composition, but add randomness for deviations.
5. **Progressive Introduction**: Start with basic submarines, then elite/flagship, then surface/carrier diversions.
