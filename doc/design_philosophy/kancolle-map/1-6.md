# Kantai Collection Map 1-6 Design Philosophy

## Map Overview
**World 1‑6: 輸送船団護衛作戦 (Transport Convoy Escort Operation)** – Unique Extra Operation (EO) map with **no boss node**; gauge reduces by 1/7 each time fleet reaches home port (N node). Introduces transportation fleet escort mechanics with strict ship restrictions.

### Purpose
- **Transport Escort Tutorial**: First map focused on escorting convoys rather than defeating a boss fleet.
- **Gauge‑Reduction Mechanic**: Gauge decreases by 1/7 per N‑node arrival; 7 arrivals clear map.
- **Ship‑Type Restrictions**: No battleships, standard carriers, armored carriers, torpedo cruisers, submarines, or submarine carriers allowed.
- **Air‑Combat Introduction**: Features dedicated air‑combat nodes (D, F, L) where only aerial battles occur.
- **Resource‑Gathering Focus**: N node yields random resources (fuel/ammo/steel/bauxite), providing economic incentive.

### Difficulty
- **Rank**: ☆☆☆☆☆ (Easy – but routing complexity adds challenge)
- **Recommended Fleet**: Light cruisers, destroyers, aviation battleships, light carriers, seaplane tenders.
- **Resource Cost**: Variable (combat nodes consume fuel/ammo; N node gives resources back).
- **Repair Cost**: Low if proper routing followed; risk of damage at combat nodes B, K, J.
- **Special Mechanics**: No boss, gauge‑reduction by reaching home port, strict ship restrictions, air‑combat‑only nodes.

### Unlock Requirements
- **Progression**: Available after clearing 1‑5.
- **No special requirements**: Unlocked after 1‑5 completion.

## Routing Rules

### Branching Conditions (Based on “ルート分岐法則” section)
Rules are evaluated top‑down; first matching condition applies.

| Branch Point | Destination | Condition |
|--------------|-------------|-----------|
| **Start** → **A** | **C** | Fleet contains **aviation battleship, light carrier, or heavy cruiser**. |
| | **C** | Fleet contains **≥2 aviation cruisers**. |
| | **C** | Fleet has **≤3 ships total (destroyers + coastal defense ships)**. |
| | **A** | **All other cases**. |
| **G** → **F** | **F** | Fleet has **exactly 1 light cruiser AND exactly 5 ships (destroyers + coastal defense ships)**. |
| | **Random** | **All other cases** (75% F, 25% K). |
| **M** → **J** | **L** | Fleet contains **≥3 ships among (aviation battleships + heavy cruisers + light carriers)**. |
| | **L** | Fleet contains **≥3 ships among (aviation battleships + heavy cruisers + aviation cruisers)**. |
| | **L** | Fleet has **≤2 ships (destroyers + coastal defense ships)**. |
| | **L** | **Recon score < 28?** (exact threshold unclear). |
| | **Random** | **Recon score between 28? and 30** (exclusive). |
| | **J** | **Recon score ≥ 30**. |

**Notes on ship classification** (from wiki):
- “軽巡級” = light cruisers + training cruisers **+ torpedo cruisers** (but torpedo cruisers are prohibited from sortie).
- “航空戦艦” = aviation battleships (allowed).
- “軽空母” = light carriers (allowed).
- “重巡” = heavy cruisers (allowed).
- “航巡” = aviation cruisers (allowed).
- “駆逐” = destroyers (allowed).
- “海防” = coastal defense ships (allowed).

**Recon Score Details**:
- **Branch‑point coefficient**: 3 (for this map).
- **Score calculation**: Uses standard recon‑score formula (see Kancolle wiki).
- **HQ‑level adjustment**: Values shown are for **HQ level 120**. Lower HQ levels need +1 margin for safety.

### Design Intent
- **South Route (A→E→G→F→B→N)**: Optimal resource‑farming route. Requires 1 light cruiser + 5 destroyers/coastal defense ships.
- **Middle/Upper Routes (C→H→K→…)**: Heavier combat paths for players who include aviation battleships, heavy cruisers, or light carriers.
- **Strict Prohibitions**: Battleships, standard carriers, armored carriers, torpedo cruisers, submarines banned – forces use of escort‑focused ships.
- **Recon‑Based Branching**: Encourages players to balance combat power with recon capability.

## Resource Nodes

### Node N: 母港 (Home Port) – Resource Awards
**During gauge existence** (pre‑clear):
- **Fuel**: 300, 500, 700, or 1000
- **Ammo**: 300 or 500
- **Steel**: 100 or 300
- **Bauxite**: 100 or 200

**After gauge destruction** (post‑clear):
- **Fuel**: 50, 70, or 100
- **Ammo**: 50, 70, or 100
- **Steel**: 50, 70, or 100
- **Bauxite**: 50 only

**Special**: On final gauge destruction (7th arrival), fuel award is **fixed at 1000**.

### Design Intent
- **Economic Incentive**: Rewards players for completing sorties with random resources.
- **Diminishing Returns**: Post‑clear rewards are much lower, discouraging farming after map completion.
- **Risk‑Reward Balance**: Heavier combat routes (middle/upper) offer same resource rewards as safe south route – encourages efficient south‑route farming.

## Design Patterns Observed

### 1. No‑Boss EO Mechanic
- **Gauge Reduction by Arrival**: Each N‑node arrival reduces gauge by 1/7; 7 arrivals clear map.
- **Monthly Reset**: Gauge resets at beginning of month; special combat results deadline: end‑of‑month 21:59; present‑box deadline: 23:59.
- **Rewards**: Clear reward = present box ×1 + special combat results +75.
- **Post‑Clear**: After deadline, logging out/in removes clear mark and restores gauge.

### 2. Transportation Escort Focus
- **Ship Restrictions**: No battleships, standard carriers, armored carriers, torpedo cruisers, submarines – forces use of escort‑appropriate ships.
- **Light Fleet Emphasis**: Optimal route requires 1 light cruiser + 5 destroyers/coastal defense.
- **Real‑World Analogy**: Simulates convoy escort operations with limited heavy units.

### 3. Air‑Combat‑Only Nodes
- **Dedicated Air Battles**: Nodes D, F, L feature only aerial combat (no surface engagement).
- **Two‑Phase Combat**: Air combat occurs twice (opening + second phase); enemy ships can be damaged by aircraft.
- **Anti‑Air Focus**: Requires strong anti‑air equipment and fighter coverage.
- **Resource Conservation**: No torpedo phase; reduced damage compared to full combat nodes.

### 4. Recon‑Based Branching
- **Recon Score Matters**: Branch at M depends on recon score (≥30 for J, <28? for L, random between).
- **HQ‑Level Adjustment**: Thresholds scale with HQ level (120 shown).
- **Strategic Choice**: Players must balance combat power with recon capability.

### 5. Damage‑Control Exploitation
- **Safe Retreat Points**: Nodes B and D allow retreat even if flagship is heavily damaged (no sinking risk).
- **Damage‑Consume Strategy**: Flagship with damage control can advance even if heavily damaged at B/D (consumable not used at N).
- **Risk Management**: Encourages strategic use of damage‑control equipment.

### 6. Economic Gameplay
- **Resource‑Positive Sorties**: South route can yield net resource gain (rewards exceed consumption).
- **Farming Viability**: Can be farmed for resources using disposable (“sacrificial”) ships.
- **Diminishing Returns**: Post‑clear rewards drop significantly, balancing economy.

## Implementation Notes for FleetMemories

### Adaptation Considerations
1. **No‑Boss EO System**: Implement gauge‑reduction‑by‑arrival instead of boss‑kill requirement.
2. **Ship Restrictions**: Enforce prohibition of battleships, standard carriers, armored carriers, torpedo cruisers, submarines.
3. **Air‑Combat‑Only Nodes**: Create new battle type for aerial‑only combat (two air phases).
4. **Recon‑Based Branching**: Add recon‑score calculations with map‑specific coefficient (3).
5. **Resource‑Reward System**: Implement random resource awards at goal node with pre‑/post‑clear differences.
6. **Damage‑Control Mechanics**: Allow damage‑control use without consumption at non‑combat goal nodes.

### Suggested FleetMemories Implementation Options

**Option 3: Hybrid Approach**
- **Deterministic First Clear**: Guaranteed south route for first few sorties (tutorial).
- **Branching After Tutorial**: Introduce full branching after player understands mechanics.
- **Adjustable Complexity**: Let players choose between simple (south) or complex (middle/upper) routes.
