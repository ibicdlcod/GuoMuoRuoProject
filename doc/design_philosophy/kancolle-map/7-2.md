# Kantai Collection Map 7-2 Design Philosophy
**Operation Celebes Sea Combat Patrol** (セレベス海戦闘哨戒)

## Map Overview
- **Purpose**: First normal map with **dual HP gauges**; introduces two‑phase progression: first gauge (submarine boss) unlocks second gauge (carrier task force boss). Tests anti‑submarine warfare (ASW) for first phase, then surface fleet combat for second phase.
- **Difficulty**: ☆☆☆☆☆☆☆☆ (8 stars)
- **Unlock Requirements**: **7‑1 clear**
- **HP Gauges**:
  - **First Gauge (G node)**: Boss flagship sink reduces gauge by **⅓ (33.3%)**; 3 sinks required to destroy gauge and unlock H–M nodes
  - **Second Gauge (M node)**: Boss flagship sink reduces gauge by **¼ (25%)**; 4 sinks required to clear map
  - **Gauge reduction only on flagship sink** (damage alone does not reduce gauge)
- **Monthly Reset**: **Both gauges reset on the 1st of each month**, but **no Medal or Special War Results rewards** (unlike Extra Operations)
- **Submarine Nodes**: C, E, G (boss1) have **submarine effect** – fuel 8% consumption (no ammo loss) at C/E; fuel 20%, ammo 20% consumption at G
- **Air Raid Node (H)**: **Air raid effect** – fuel 6%, ammo 4% consumption
- **Resource Nodes**: A (whirlpool – fuel loss), K (fuel gain)
- **BGM**:
  - Map: 「敵地侵入」
  - Route combat: 「激戦！遊撃部隊」
  - Boss day: 「機動部隊を追え！」 (until 2020/03/27)
  - Boss night: 「泡沫のシャングリア」 (until 2020/03/27)
  - Boss battle: 「鶴墜ちる海」 (after 2020/03/27)

## Node Layout
```
Start → A/B/C → (A: whirlpool) → (B: surface combat) → (C: submarine combat) → (D/E) → (E: submarine combat) → (F/G) → (G: boss1) → (H/I) → (I: surface combat) → (J/K/L/M) → (M: boss2)
```
**Key Routes**:
- **First‑gauge shortest (CEG)**: Start → C → E → G (requires 4‑5 ship fleet with ≥3 Destroyer+Escort)
- **Second‑gauge shortest (C→E→H→I→M)**: After first gauge cleared, Start → C → E → H → I → M (requires fleet composition and LoS checks)

**Node Types**:
- **A**: Whirlpool (うずしお) – fuel loss (base 30%, reduced by radar count)
- **B**: **Surface Combat** – Deep‑Sea Task Force Forward Invasion Torpedo Squadron (軽巡ヘ級flagship, 軽巡ツ級, 駆逐ロ級後期型)
- **C**: **Submarine Battle** – Celebes Sea Area Patrol Submarine I Group (潜水カ級elite, 潜水カ級)
- **D**: **No Combat** (気のせいだった)
- **E**: **Submarine Battle** – Celebes Sea Area Patrol Submarine II Group (潜水カ級elite, 潜水カ級)
- **F**: **No Combat** (気のせいだった)
- **G (Boss1)**: **Submarine Battle** – Celebes Sea Area Flagship Patrol Submarine (潜水ソ級elite/flagship, 輸送ワ級, 駆逐ロ級後期型)
- **H**: **Air Raid** – Deep‑Sea Task Force Main Carrier Task Force Group (空母ヲ級改flagship, 軽母ヌ級elite, 重巡ネ級)
- **I**: **Surface Combat** – Deep‑Sea Task Force Vanguard Patrol Group (軽巡ヘ級flagship, 重巡リ級flagship, 駆逐ロ級後期型)
- **J**: **No Combat** (敵影を見ず)
- **K**: **Resource Node** – Fuel +25~40 (increments of 5; +2 with drum cans, +3 with landing craft)
- **L**: **No Combat** (敵影を見ず)
- **M (Boss2)**: **Surface Combat** – Deep‑Sea Task Force Main Carrier Task Force Group (空母ヲ級改flagship, 軽母ヌ級elite/flagship, 重巡ネ級elite, 軽巡ツ級elite)

## Routing Rules
**Key Branching Conditions** (based on fleet size, ship types, LoS):

### Start → A / B / C
- **To A** if ANY of:
  - **(Destroyer + Escort) ≤1**
  - Fleet includes **submarine**
  - **6‑ship fleet** AND:
    - Regular Carriers ≥2
    - (Battleship‑type + Regular Carrier) ≥4
    - (Light Cruiser + Training Cruiser) ≥3
  - **5‑ship fleet** AND:
    - Regular Carriers ≥3
    - (Battleship‑type + Regular Carrier) ≥1
    - (Light Cruiser + Training Cruiser) ≥2
    - Escort ≤2
- **To B** if ANY of:
  - **5‑ship fleet** AND (Battleship‑type + Regular Carrier) ≥1
  - **5‑ship fleet** AND (Light Cruiser + Training Cruiser) ≥2
  - **5‑ship fleet** AND Escort ≤2
  - **≤4‑ship fleet** AND (Battleship‑type + Regular Carrier) ≥1
  - **≤4‑ship fleet** AND (Destroyer + Escort) ≤2
- **To C** otherwise (light fleet with ≥3 Destroyer+Escort, no battleship/carrier)

### C → D / E
- **To D** if ANY of:
  - Fleet includes **supply ship**
  - Fleet includes **submarine**
  - **6‑ship fleet** AND (Battleship‑type + Regular Carrier) ≥1
  - **5‑ship fleet** AND (Battleship‑type + Regular Carrier) ≥2
  - **≤4‑ship fleet** AND (Battleship‑type + Regular Carrier) ≥2
- **To E** if ANY of:
  - **6‑ship fleet** AND (Destroyer + Escort) ≥4
  - **5‑ship fleet** AND (Destroyer + Escort) ≥4
  - **5‑ship fleet** AND Escort ≥3
  - **≤4‑ship fleet** AND (Destroyer + Escort) ≥3
  - **≤4‑ship fleet** AND Escort ≥2
- **Otherwise D**

### E → F / G
- **To G** if ANY of:
  - **≤5‑ship fleet**
  - **(Destroyer + Escort) ≥5**
  - Destroyer ≥1 AND Escort ≥3
  - **LoS score ≥46?** (HQ Lv 120; branch coefficient 4)
- **To F** if **LoS insufficient**
- **Otherwise random**

### H → I / (I‑biased random)
- **To I** if ANY of:
  - **Fast+ unified speed**
  - (Battleship‑type + Carrier‑type) ≥4
  - Fast unified speed AND (Battleship‑type + Carrier‑type) ≥3
- **Random (65% I, 35% ?)** if (Battleship‑type + Carrier‑type) =2
- **To I** if (Battleship‑type + Carrier‑type) ≤1

### I → J / L / M
- **To J** if ANY of:
  - Fleet includes **supply ship**
  - Seaplane Tender ≥1 AND (Destroyer + Escort) ≥3
- **To L** if **LoS score <63?** (HQ Lv 120)
- **Random** if **LoS score 63?‑68?**
- **To M** if **LoS score ≥69**

**Notes**:
- **Speed classification**: "Fast+ unified" = all ships Fast+ (高速+統一)
- **LoS calculation**: Branch coefficient **4**; values given for HQ Lv 120; lower HQ levels need +1 margin
- **Ship type definitions**: "Light Cruiser‑type" includes Light Cruiser, Training Cruiser, **Torpedo Cruiser** (雷巡)
- "Battleship‑type" includes Fast Battleship, (Slow) Battleship, Aviation Battleship
- "Carrier‑type" includes Regular Carrier, Armored Carrier, Light Carrier (but **Auxiliary Carrier** counts as Supply Ship)

## Design Patterns Observed
1. **Dual‑Gauge Progression**: First gauge (submarine boss) must be cleared to unlock second gauge (carrier task force boss), creating two distinct combat phases.
2. **Monthly Reset without Rewards**: Gauges reset monthly like EO, but no Medal/Special War Results – encourages repeated play for farming rather than reward collection.
3. **Submarine‑to‑Surface Transition**: Forces players to build fleets capable of both ASW (first phase) and surface/air combat (second phase).
4. **Fleet‑Size‑Based Branching**: Extensive branching conditions vary by fleet size (6‑ship, 5‑ship, ≤4‑ship), promoting different fleet compositions for each phase.
5. **LoS‑Gated Final Boss**: Second boss requires high LoS (≥69 at HQ Lv 120) to reach, encouraging equipment optimization.
6. **Air Raid Node**: Introduces air raid node with percentage resource consumption, adding strategic resource management.
7. **Escort‑Focused Routing**: Many branches consider Escort (海防艦) separately from destroyers, giving them unique routing value.
8. **Speed‑Based Branching**: Uses "Fast+ unified" condition to route away from air raid node, rewarding speed‑optimized fleets.
9. **Post‑Clear Weakening**: Both boss nodes have weaker patterns after gauge destruction, enabling efficient farming.
10. **HQ Level Scaling**: Second boss patterns scale with HQ level (≤106 vs ≥107), maintaining challenge for veteran players.
11. **Limited‑Time Drop Incentives**: Included rare Escort ships (Matsuwa, Sado) during limited period, driving player engagement.
12. **Resource Node with Equipment Bonus**: Node K rewards drum cans/landing craft, encouraging auxiliary equipment.
13. **Whirlpool with Radar Mitigation**: Node A's fuel loss can be reduced by radar count, teaching equipment utility.
14. **Two‑Boss Farming**: After clear, both bosses become farmable for different ship pools (submarine boss for destroyers/light cruisers, carrier boss for battleships/carriers).
15. **Complex Routing Tables**: Requires players to consult detailed branching tables, promoting community knowledge sharing.

## Implementation Notes for FleetMemories
1. **Dual HP Gauge System**: Implement two independent gauges; first gauge destruction unlocks new nodes (H‑M); second gauge destruction clears map.
2. **Monthly Reset Logic**: Reset both gauges on 1st of each month, but do not award Medal/Special War Results.
3. **Submarine Node Effects**: Apply 8% fuel consumption at C/E, 20% fuel/ammo at G.
4. **Air Raid Node**: Apply 6% fuel, 4% ammo consumption at H; use air combat mechanics without surface engagement.
5. **Fleet‑Size‑Dependent Branching**: Implement separate branching tables for 6‑ship, 5‑ship, and ≤4‑ship fleets.
6. **LoS‑Based Branching**: Use LoS calculation with branch coefficient 4; adjust thresholds for player HQ level.
7. **Speed‑Based Branching**: Check "Fast+ unified" condition (all ships Fast+ speed).
8. **Escort Ship Category**: Treat Escort as separate from destroyers for routing calculations.
9. **Post‑Clear Weakening**: Swap boss patterns to weaker versions after gauge destruction.
10. **HQ Level Scaling**: Scale enemy patterns based on player level (threshold at 106/107).
11. **Resource Node with Equipment Multipliers**: Implement fuel gain with drum/landing craft bonuses at K.
12. **Whirlpool with Radar Reduction**: Apply fuel loss percentage reduced by radar count (0‑6).
13. **Limited‑Time Drop Events**: Support time‑limited drop tables for special ships (Matsuwa, Sado).
14. **Two‑Phase Fleet Building**: Design quests/tutorials that guide players to build ASW fleet first, then transition to surface fleet.
15. **Community Documentation**: Provide in‑game branching hints or reference to external tables for advanced players.
16. **Farming Optimization**: Balance experience rewards to make both bosses attractive for leveling different ship types.
17. **Equipment Synergy**: Encourage radar for whirlpool reduction, drum cans for resource nodes, ASW gear for first phase, AA guns for air raid node.
18. **Map Unlock Chain**: Require 7‑1 clear to access; clearing 7‑2 unlocks 7‑3.
19. **Quarterly Quest Integration**: Include quest "セレベス海方面の哨戒を実施せよ！" requiring boss1 S‑rank victories.
20. **Combined Fleet Restriction**: Do not allow combined fleet on this map (single fleet only).
