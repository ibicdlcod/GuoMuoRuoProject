# Kantai Collection Map 7-1 Design Philosophy
**Operation Brunei Anchorage Patrol** (ブルネイ泊地沖哨戒)

## Map Overview
- **Purpose**: First normal map with HP gauge mechanics; introduces submarine‑heavy combat with surface threat (G node). Tests anti‑submarine warfare (ASW) capability and light fleet routing.
- **Difficulty**: ☆☆☆☆☆ (5 stars)
- **Unlock Requirements**: **2‑4 clear**
- **HP Gauge**: Boss flagship sink reduces gauge by **⅓ (33.3%)**; 3 sinks required for clear
  - **Gauge reduction only on flagship sink** (damage alone does not reduce gauge)
- **Main Resource**: Fuel (appears at resource nodes E and I)
- **Submarine Nodes**: D, F, H have **submarine effect** – fuel 8% consumption, no ammo loss
- **Boss Node (K)**: **Submarine effect** – fuel 20%, ammo 20% consumption
- **BGM**:
  - Map: 「捷号決戦前夜」
  - Route combat: 「新編「海上護衛隊」抜錨！」
  - Boss day: 「敵地侵入！」
  - Boss night: 「モドレナイノ」

## Node Layout
```
Start → B/D/F → (B→A/C) → (D→C/E) → (E→H/I/J/K) → (G fixed after E?) → H → K (Boss)
```
**Common Routes**:
- **5‑ship route (DEGHK)**: Start → D → E → G → H → K (recommended: Light Cruiser 1 + Destroyer 4)
- **4‑ship route (FGHK)**: Start → F → G → H → K (recommended: Light Cruiser 2 + Destroyer 2, or Torpedo Cruiser 2 + Light Cruiser 1 + Destroyer 1)

**Key Node Types**:
- **A**: Whirlpool (うずしお) – ammunition loss (base 35%, reduced by radar)
- **B**: **Surface Combat** – Enemy Commerce Raiding Invasion Fleet (軽巡ヘ級flagship, 重巡ネ級elite, 軽母ヌ級flagship)
- **C**: **Surface Combat** – Enemy Commerce Raiding Invasion High‑Speed Mobile Force (空母ヲ級flagship, 戦艦タ級flagship, 重巡ネ級elite)
- **D**: **Submarine Battle** – Deep‑Sea Submarine Fleet II Group (潜水ソ級elite, 潜水カ級) – fuel 8%, no ammo
- **E**: **Resource Node** – Fuel +10~20 (increased by drum cans/landing craft)
- **F**: **Submarine Battle** – Deep‑Sea Submarine Fleet III Group (潜水ヨ級elite, 潜水カ級) – fuel 8%, no ammo
- **G**: **Surface Combat** – Enemy Patrol Unit (軽巡ヘ級flagship, 駆逐ロ級後期型) – main surface threat, risk of torpedo criticals
- **H**: **Submarine Battle** – Deep‑Sea Submarine Fleet I Group (潜水ヨ級elite, 潜水ソ級elite) – fuel 8%, no ammo
- **I**: **Resource Node** – Fuel +30~50 (increased by drum cans/landing craft)
- **J**: **No Combat** (敵影を見ず) – evasion node
- **K (Boss)**: **Submarine Battle** – Deep‑Sea Submarine Fleet Flagship Squadron (潜水ソ級flagship, 潜水カ級elite, 潜水ヨ級elite) – fuel 20%, ammo 20%

## Routing Rules
**Key Branching Conditions**:

### Start → B / D / F
- **To B** if ANY of:
  - Fleet includes **submarine**
  - **(Battleship‑type + Carrier‑type) ≥1**
  - **6 ships**
- **To D** if ANY of:
  - **5 ships** (and no battleship/carrier)
  - Fleet includes **supply ship**
- **To F** if **≤4 ships** (and no battleship/carrier/submarine/supply ship)

### B → A / C
- **To A** if ANY of:
  - **(Battleship‑type + Regular Carrier) ≥1**
  - **Light Carrier ≥2**
  - **Heavy Cruiser‑type ≥3**
- **To C** if **(Destroyer + Escort) ≥2**
- **Otherwise random**

### D → C / E
- **To E** if ANY of:
  - **Light Cruiser =1 AND Destroyer =4** (standard 5‑ship route)
  - **Destroyer ≥1 AND Escort ≥3**
  - **Supply ship ≥1 AND Escort ≥3**
  - **(Destroyer + Escort) =5**
  - **(Destroyer + Escort) =4 AND** (includes Training Cruiser OR Supply Ship)
- **To C** otherwise (or random if Seaplane Tender present with 4 DD+Escort)

### E → H / I / J / K
- **To K** (boss) if ANY of:
  - **Light Cruiser ≥1 AND Destroyer ≥4**
  - **Destroyer ≥1 AND Escort ≥3**
- **To I or K random** if **Supply ship ≥1**
- **To J** if **(Battleship‑type + Carrier‑type) ≥2**
- **To random** if **(Battleship‑type + Carrier‑type) =1**
- **Otherwise random** with probabilities:
  - I: 20‑25%
  - J: 5‑10%
  - K: 70‑75%

**Note**: Node G is a **fixed combat node** after E when heading to H (and subsequently K). The branching table does not list G because it is not a decision point.

## Design Patterns Observed
1. **First HP Gauge Map**: Introduces HP gauge mechanics in normal (non‑EO) maps, requiring flagship sink for gauge reduction.
2. **Submarine‑Focused Gameplay**: Heavy emphasis on anti‑submarine warfare; multiple submarine nodes drain fuel.
3. **Light Fleet Requirement**: Penalizes large ships (battleships/carriers) and 6‑ship fleets, forcing players to use 4‑5 ship light fleets.
4. **Surface Threat amid ASW**: Node G provides a surface combat challenge in an otherwise submarine‑heavy map, testing fleet versatility.
5. **Resource Node Incentives**: Fuel nodes reward players who bring drum cans/landing craft, encouraging equipment choices.
6. **Branching Complexity**: Multiple conditional branches based on exact ship counts and types (Light Cruiser 1 + Destroyer 4) teach precise fleet building.
7. **Escort Ship Mechanics**: Introduces Escort (海防艦) as separate category from destroyers for routing.
8. **Boss‑Only Sink Requirement**: Gauge only reduces on flagship sink, not on damage, teaching target‑priority management.
9. **Low‑Cost Farming Potential**: After clear, map becomes efficient for leveling destroyers/light cruisers and earning player experience.
10. **Rare Drop Inclusion**: Boss node drops previously event‑limited ships (Sagiri, Arashi, Hagikaze, Mikuma), adding collection incentive.

## Implementation Notes for FleetMemories
1. **HP Gauge System**: Implement ⅓ reduction per boss sink, 3 sinks to clear; gauge reduction only on flagship sink.
2. **Submarine Node Effects**: Apply percentage‑based fuel consumption (8%) at nodes D, F, H; boss node 20% fuel/ammo.
3. **Light Fleet Routing**: Enforce branching conditions that penalize battleships/carriers and 6‑ship fleets; reward 4‑5 ship light fleets.
4. **Surface Combat Integration**: Include a single surface combat node (G) amidst submarine nodes to force ASW‑capable ships to also handle surface threats.
5. **Resource Node Bonuses**: Implement fuel gain with drum/landing craft multipliers (E: +10‑20, I: +30‑50).
6. **Escort Ship Category**: Treat Escort (海防艦) as separate from destroyers for routing calculations.
7. **Precise Branching Conditions**: Implement exact ship‑count conditions (e.g., Light Cruiser =1 AND Destroyer =4) for optimal routing.
8. **Boss Submarine Flagship**: Use 潜水ソ級flagship as boss with elite submarine escorts; apply high evasion/submarine mechanics.
9. **Drop Table Rarity**: Include rare destroyers (Sagiri, Arashi, Hagikaze) and heavy cruiser Mikuma as boss‑only drops.
10. **Player Experience Balance**: Set experience rewards to encourage farming (250 per node, 3500 boss) while maintaining risk at node G.
11. **Equipment Synergy**: Require ASW equipment (sonar/depth charge) for efficient clears; allow drum cans for resource bonuses.
12. **Map Unlock Chain**: Require 2‑4 clear to access; unlocking 7‑1 opens 4‑2 and 7‑2.
13. **Monthly Quest Integration**: Include quarterly quest "泊地周辺海域の安全確保を徹底せよ！" requiring boss S‑rank victories.
14. **Smoke Screen Mechanic**: Allow smoke screen equipment to reduce damage at node G, providing alternative strategy.
15. **Combined Fleet Restriction**: Do not allow combined fleet on this map (single fleet only).
