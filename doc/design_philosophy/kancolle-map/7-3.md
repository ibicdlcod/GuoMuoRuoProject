# Kantai Collection Map 7-3 Design Philosophy
**Operation Break Through the Malacca Strait** (マラッカ海峡を抜けて)

## Map Overview
- **Purpose**: First normal map with **historical ship routing control**; recreates the Penang Naval Battle using specific historical ships (Haguro, Kamikaze, Ashigara) to unlock optimal routes. Tests light fleet combat with PT boat threats and dual‑gauge progression.
- **Difficulty**: ☆☆☆☆☆☆☆☆ (8 stars)
- **Unlock Requirements**: **7‑2 clear**
- **HP Gauges**:
  - **First Gauge (E node)**: Boss flagship sink reduces gauge by **⅓ (33.3%)**; 3 sinks required to destroy gauge and unlock G–P nodes
  - **Second Gauge (P node)**: Boss flagship sink reduces gauge by **¼ (25%)**; 4 sinks required to clear map
  - **Gauge reduction only on flagship sink** (damage alone does not reduce gauge)
- **Monthly Reset**: **Both gauges reset on the 1st of each month**, but **no Medal or Special War Results rewards** (unlike Extra Operations)
- **Special Node Effects**:
  - **Submarine Node (J)**: Submarine effect – fuel 8% consumption, no ammo loss
  - **Whirlpool Nodes (K, L)**: Fuel loss (base percentage unknown, reduced by radar count)
  - **Resource Nodes**: H (fuel +30–50), O (bauxite +40–50) – increased by drum cans/landing craft
- **BGM**:
  - Map: 「海峡へ」
  - Route combat: 「第五戦隊の出撃」
  - Boss battle: 「第五艦隊の奮戦」

## Node Layout
```
Start → A → (B/C) → (C fixed) → (D/E) → (E: boss1) → (after gauge clear) G–P nodes open
```
**Key Routes**:
- **First‑gauge shortest (A‑C‑E)**: Requires Haguro + Kamikaze + (Ashigara or Myōkō) + 1 ship (4‑ship fleet)
- **Second‑gauge shortest (A‑C‑D‑G‑P)**: After first gauge cleared, requires Haguro + Ashigara + Kamikaze + (Light Cruiser/Seaplane Tender) + 2 Destroyers (6‑ship, fast unified)

**Node Types**:
- **A**: **No Combat** (start decision point)
- **B**: **PT Boat Combat** – Deep‑Sea Eastern Force Torpedo Boat Squadron (駆逐イ級後期型, PT小鬼群)
- **C**: **Surface Combat** – Deep‑Sea Eastern Force Vanguard Destroyers (駆逐ロ級後期型, 駆逐イ級)
- **D**: **Surface Combat** – Deep‑Sea 5,500‑ton Light Cruiser (軽巡ホ級flagship, destroyer escorts)
- **E (Boss1)**: **Surface Combat** – Deep‑Sea Eastern Force Elite Destroyer Division (駆逐ロ級後期型/elite, 駆逐ロ級)
- **F**: **No Combat** (敵影を見ず)
- **G**: **No Combat** (マラッカ海峡を抜ける…対潜警戒を厳にせよ！)
- **H**: **Resource Node** – Fuel +30–50 (increments of 5; +2 with drum cans, +3 with landing craft)
- **I**: **No Combat** (我、マラッカ海峡を突破、アンダマン海へ！)
- **J**: **Submarine Battle** – Deep‑Sea Submarine Fleet Strait Patrol Line (潜水ヨ級flagship/elite, 潜水カ級)
- **K, L**: **Whirlpool** – Fuel loss (reduced by radar)
- **M**: **Surface Combat** – Deep‑Sea Eastern Force Cruiser Squadron (重巡リ級flagship, 雷巡チ級elite, 駆逐ロ級後期型)
- **N**: **Surface Combat** – Deep‑Sea Eastern Force Carrier Mobile Force (軽母ヌ級改elite/flagship, 戦艦タ級elite, 軽巡ツ級elite)
- **O**: **Resource Node** – Bauxite +40–50 (increments of 5; +2 with drum cans, +6 with landing craft)
- **P (Boss2)**: **Surface Combat** – Deep‑Sea Eastern Force Strait Blockade Flagship (重巡ネ級elite, 軽巡ツ級elite, 駆逐ロ級後期型elite)

## Routing Rules
**Key Branching Conditions** (historical ship dependency, fleet size, speed):

### First Gauge (before P node appears)
- **Start (A) → B / C**:
  - **To C** if ANY of:
    - **1‑ship fleet**
    - **Haguro AND Kamikaze present**
    - **4‑ship fleet** consisting only of (Heavy Cruiser + Light Cruiser + Destroyer + Escort)
  - **To B** otherwise (includes carriers, no heavy cruisers, 5+ ships)
- **C → D / E**:
  - **To E** if ANY of:
    - **2‑ship or smaller fleet**
    - **Haguro AND Kamikaze present** AND (Ashigara OR Myōkō present)
    - **4‑ship fleet** with Haguro AND 3 Destroyer+Escort
    - **4‑ship fleet** with Kamikaze AND 4 Destroyer+Escort
  - **To D** otherwise (includes battleships/carriers, heavy cruiser ≥2, etc.)
- **D → E / F**:
  - **To F** if ANY of:
    - (Battleship‑type + Carrier‑type) ≥1
    - **6‑ship fleet**
    - Heavy Cruiser‑type ≥4
    - Aviation Cruiser ≥2
  - **To E** otherwise

### Second Gauge (after P node appears)
- **Start (A) → B / C**:
  - **To C** if ANY of:
    - **1‑ship fleet**
    - **Supply ship 1 AND (Destroyer + Escort) ≥3**
    - **Haguro AND Kamikaze present**
    - **5+‑ship fleet** with Haguro absent AND no slow ships
  - **To B** otherwise (includes carriers, no heavy cruisers, etc.)
- **C → D / I / E**:
  - **To I** if **fastest unified speed**
  - **To D** if ANY of:
    - (Battleship‑type + Carrier‑type) ≥1
    - (Destroyer + Escort) =0
    - **6‑ship fleet**
    - **5+‑ship fleet** with fast+ unified AND (Light Cruiser + Destroyer) ≥4
    - **5+‑ship fleet** with fast unified AND 1 Heavy Cruiser + 1 Light Cruiser + 3 Destroyers
  - **To E** if **2‑ship or smaller fleet**
- **G → H / I / J / K / P**:
  - **To P** if **Haguro AND Kamikaze present** AND ANY of:
    - **4‑ship or smaller fleet**
    - **Fast+ unified speed**
    - **Ashigara present**
  - **To J** if ANY of:
    - (Battleship‑type + Carrier‑type) ≥1
    - (Destroyer + Escort) ≤2
    - Heavy Cruiser‑type ≥3
    - Slow speed included
  - **To I** otherwise
- **I → J / K / P**:
  - **To J** if ANY of:
    - (Battleship‑type + Carrier‑type) ≥1
    - Heavy Cruiser‑type ≥3
    - (Destroyer + Escort) =0
    - **Fast+ unified** AND (Destroyer + Escort) ≥3
  - **To P** if **Haguro AND Kamikaze present** AND **Ashigara present** AND (Destroyer + Escort) ≥3
  - **To K** otherwise
- **M → J / P**:
  - **To P** if ANY of:
    - **Destroyer ≥3** AND (Haguro AND Ashigara) OR (Haguro AND Kamikaze) present
    - **Destroyer =2** AND Haguro AND Kamikaze AND Ashigara present
  - **To J** otherwise (includes battleships/carriers, slow ships, heavy cruiser ≥4)
- **N → N / O / P**:
  - **To N** if ANY of:
    - Regular Carrier present
    - (Battleship‑type + Carrier‑type) ≥2
    - Submarine ≥4
  - **To O** if ANY of:
    - (Slow) Battleship present
    - Supply ship present
    - Seaplane Tender ≥2
  - **To P** otherwise

**Notes**:
- **Historical Ship Definitions**:
  - **Haguro** (羽黒) – required for many shortest routes
  - **Kamikaze** (神風) – often paired with Haguro
  - **Ashigara** (足柄) or **Myōkō** (妙高) – interchangeable for some conditions
- **Speed Categories**: "Fast+ unified" (高速+統一), "Fast unified" (高速統一), "Fastest unified" (最速統一)
- **Fleet Size Matters**: First gauge favors ≤4 ships; second gauge allows up to 6 ships but with composition restrictions

## Design Patterns Observed
1. **Historical Ship Routing**: First map where specific historical ships (Haguro, Kamikaze, Ashigara) are required for optimal routing, recreating the Penang Naval Battle.
2. **PT Boat Introduction**: First appearance of PT boats in normal maps, requiring specialized anti‑PT equipment (small‑caliber guns, machine guns).
3. **Light Fleet Requirement**: First gauge prohibits battleships/carriers and 6‑ship fleets, forcing ≤4‑ship light fleets.
4. **Dual‑Gauge with Monthly Reset**: Continues 7‑2 pattern of two gauges resetting monthly but without EO rewards.
5. **Speed‑Based Branching**: Extensive use of speed categories (fast+, fast, fastest) for routing in second gauge.
6. **Resource Node Variety**: Includes both fuel and bauxite nodes with landing craft bonuses, encouraging auxiliary equipment.
7. **Whirlpool with Radar Mitigation**: Teaches radar utility for resource conservation.
8. **All‑Destroyer Boss**: First boss (E) is composed entirely of destroyers, teaching players to handle high‑evasion, low‑armor enemies.
9. **Heavy Cruiser Flagship Boss**: Second boss (P) features heavy cruiser flagship with elite escorts, requiring night battle for reliable S‑rank.
10. **Carrier‑Battleship Node (N)**: Optional high‑threat node with carrier air power and battleship, providing risk/reward choice.
11. **Mission Integration**: Numerous one‑time and quarterly missions require specific historical ship compositions and boss victories.
12. **Rare Drop Incentives**: Bosses drop previously event‑limited destroyers (Kamikaze, Asakaze, Yamakaze, etc.) and foreign ships (Gambier Bay, Luigi Torelli).
13. **Periodic Limited‑Time Drops**: Map receives periodic updates with limited‑time drop ships, driving player engagement.
14. **Narrative Integration**: Nodes G and I provide narrative text enhancing historical immersion.
15. **Complex Branching Tables**: Requires deep understanding of ship categories and historical combinations, promoting community knowledge sharing.
