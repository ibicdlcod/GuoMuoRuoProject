# Kantai Collection Map 2-1 Design Philosophy

## Map Overview
**World 2‑1: 南西諸島近海 (Nansei Islands Offshore)** – First map of World 2, introducing stronger surface enemies (elite heavy cruisers, light carriers) and resource‑node mechanics (steel, fast‑build materials).

### Purpose
- **World 2 Introduction**: Steps up difficulty from World 1, featuring elite enemies (リ級elite) and light carriers.
- **Resource‑Node Tutorial**: First map with dedicated resource nodes (steel +10‑30, fast‑build material +1).
- **Carrier‑Fleet Introduction**: Enemy carriers appear regularly (light carriers at A/D, standard carriers at F, mixed at boss).
- **Routing‑Complexity Increase**: Multiple branching points with complex conditions based on ship types/counts.
- **HQ‑Level Scaling Showcase**: Enemy patterns strengthen significantly with HQ level (post‑120 patterns).

### Difficulty
- **Rank**: ☆☆☆ (Medium – noticeable step‑up from World 1)
- **Recommended Fleet**: Balanced mix of light/heavy cruisers, destroyers, limited carriers.
- **Resource Cost**: Moderate (3‑4 combat nodes if optimal route).
- **Repair Cost**: Medium (elite heavy cruisers can deal substantial damage).
- **Special Mechanics**: Resource nodes, HQ‑level scaling, complex routing.

### Unlock Requirements
- **Progression**: Unlocked after clearing 1‑4.
- **No special requirements**: Available after 1‑4 completion.

### Node Details (Based on Kancolle Wiki)
1. **Node A: 敵上陸船団 (Enemy Landing Convoy)**  
   - **Type**: Combat node (light carriers + transports).  
   - **Purpose**: Alternative route combat; includes transport ships (ワ級).  
   - **Resource Reward**: None.

2. **Node B: アイテム獲得 (Item Acquisition)**  
   - **Type**: Resource node.  
   - **Rewards**: Steel +10‑30 (increments of 5), drum cans (+2), large‑landing‑craft series (+3).  
   - **Purpose**: Economic incentive for taking alternative route.

3. **Node C: 敵前衛部隊 (Enemy Vanguard)**  
   - **Type**: Combat node (heavy cruisers + light cruisers + destroyers).  
   - **Purpose**: First combat on main route; introduces elite heavy cruisers.

4. **Node D: 敵護衛空母群 (Enemy Escort Carrier Group)**  
   - **Type**: Combat node (light carriers + heavy cruisers).  
   - **Purpose**: Light‑carrier introduction; tests anti‑air capability.

5. **Node E: アイテム獲得 (Item Acquisition)**  
   - **Type**: Resource node.  
   - **Rewards**: Fast‑build material +1.  
   - **Purpose**: Incentive for including seaplane tenders/submarine tenders in fleet.

6. **Node F: 敵機動部隊群 (Enemy Carrier Task Force Group)**  
   - **Type**: Combat node (standard carriers + heavy cruisers).  
   - **Purpose**: Standard‑carrier introduction; significant air threat.

7. **Node G: 戦闘なし (No Combat)**  
   - **Type**: Non‑combat node (“敵影を見ず”).  
   - **Purpose**: Calm before boss on longer route.

8. **Node H: ボス 敵主力部隊 (Boss – Enemy Main Force)**  
   - **Type**: Boss combat node (battleships + carriers).  
   - **Purpose**: Map‑clear condition; features battleship‑carrier combined fleet.

## Routing Rules

### Branching Conditions (Based on “ルート分岐法則” section)
Rules are evaluated top‑down; first matching condition applies.

#### Start → C/B Branch
| Branch Point | Destination | Condition |
|--------------|-------------|-----------|
| **Start** → **C** | **B** | Fleet contains **≥3 carriers** (any type: standard/armored/light). |
| | **B** | Fleet contains **≥2 aviation battleships**. |
| | **B** | Fleet contains **≥1 supply ship AND 0 submarines**. |
| | **B/E Random** | Fleet contains **≥1 aviation battleship** AND **≥1 seaplane tender/submarine tender** → 70% B, 30% E. |
| | **B/D Random** | **All other cases** → 70% B, 30% D. |
| **Start** → **E** | **E** | Fleet contains **≥1 seaplane tender/submarine tender**. |
| | **D/E Random** | **All other cases** → 50% D, 50% E. |

#### E → H/F Branch (After C‑D‑E)
**For 6‑ship fleets:**
| Condition | Destination |
|-----------|-------------|
| Fleet contains **≥5 ships among (battleships + carriers)** | **F** |
| Fleet contains **≥1 ship among (battleships + carriers)** | **D** |
| Fleet is **6 destroyers/coastal defense ships** | **H** |
| Fleet has **1 light cruiser + 5 destroyers/coastal defense ships** | **H** |
| Fleet is **all fast (高速以上統一) + 1 light cruiser + 4 destroyers** | **H** |
| **All other cases** | **D** |

**For ≤5‑ship fleets:**
| Condition | Destination |
|-----------|-------------|
| Fleet is **5 destroyers/coastal defense ships** | **H** |
| Fleet has **1 light cruiser + 4 destroyers/coastal defense ships** | **H** |
| Fleet is **all fast + 1 light cruiser + 3 destroyers** | **H** |
| **All other cases** | **D/F Random** (60% D, 40% F). |

#### F → G/H Branch (After C‑D‑E‑F)
| Condition | Destination |
|-----------|-------------|
| Fleet contains **≥5 ships among (battleships + carriers)** | **G** |
| Fleet contains **≥3 destroyers** | **H** |
| Fleet contains **≥1 light cruiser + ≥2 destroyers** | **H** |
| **All other cases** | **H Random** (60% H, 40% ?). |

#### H → Boss (Fixed)
Once at H, proceed to boss combat.

### Design Intent
- **Carrier/Battleship Penalty**: Heavy fleets (≥3 carriers, ≥2 aviation battleships) forced to B route (dead‑end or resource‑only).
- **Optimal Route (C‑D‑E‑H)**: Requires light fleet with specific composition (1 light cruiser + 4‑5 destroyers, all fast).
- **Resource‑Node Access**: E node (fast‑build material) requires seaplane tender/submarine tender.
- **Strategic Choice**: Players must choose between heavy combat power (risk of bad routing) vs. light optimized fleet (better routing but weaker combat).

### Ship‑Classification Notes
- “軽巡級” = light cruisers + training cruisers **+ torpedo cruisers**.
- “空母系” = all carriers (standard, armored, light).
- “戦艦級” = battleships (fast + slow) + aviation battleships.
- “水母” = seaplane tenders.
- “潜水母艦” = submarine tenders.
- “補給艦” = supply ships (includes special‑duty ships, icebreakers, etc.).
- “高速以上統一” = all ships have speed ≥ fast (高速).

### Difficulty Progression
- **Enemy Tier**: Elite heavy cruisers → light carriers → standard carriers → battleship‑carrier combined fleet.
- **EXP Values**: 100‑120 (C) → 100‑170 (D) → 110‑190 (F) → 140‑220 (H).
- **Formations**: Surface nodes use 単縦/複縦, carrier nodes use 輪形.
- **Threat Level**: Air power escalates from 16‑48 (D) to 54‑162 (F/H); elite battleships have high firepower.

## Resource Nodes

### Node B: Steel Acquisition
- **Steel**: +10, +15, +20, +25, or +30 (5‑step increments)
- **Additional**: Drum cans +2, large‑landing‑craft series +3
- **Access**: Requires taking B route (carrier/battleship heavy fleets)

### Node E: Fast‑Build Material Acquisition
- **Fast‑Build Material**: +1
- **Access**: Requires fleet containing seaplane tender or submarine tender
- **Strategic Value**: Fast‑build materials are rare; encourages use of support ships.

### Design Intent
- **Economic Incentives**: Reward players for taking sub‑optimal combat routes (B) or including support ships (E).
- **Resource‑Type Introduction**: First map with fast‑build material drops.
- **Trade‑off**: Better combat route (C‑D‑E‑H) yields only one resource node (E); heavier fleets get steel (B) but worse routing.

## Design Patterns Observed

### 1. World 2 Difficulty Step‑Up
- **Elite Enemies**: リ級elite appears at first combat node (C).
- **Carrier Introduction**: Light carriers at D, standard carriers at F.
- **HQ‑Level Scaling**: Significant enemy strengthening at HQ≥120.
- **Resource Cost Increase**: More combat nodes increase fuel/ammo consumption.

### 2. Complex Routing Mechanics
- **Multiple Branch Points**: Start (C/B), E (H/F), F (G/H).
- **Fleet‑Size Conditional**: Different rules for 6‑ship vs ≤5‑ship fleets.
- **Speed Requirement**: “All fast” condition for optimal route.
- **Carrier/Battleship Penalty**: Heavy fleets punished with bad routing.

### 3. Resource‑Node Strategy
- **Steel vs Fast‑Build**: Choice between abundant steel (B) or rare fast‑build material (E).
- **Support‑Ship Requirement**: Fast‑build material requires seaplane/submarine tender.
- **Economic Trade‑off**: Better combat route yields fewer resources.

### 4. Air‑Power Progression
- **Light Carrier Phase**: Node D introduces light carriers with moderate air power.
- **Standard Carrier Phase**: Node F introduces standard carriers with higher air power.
- **Boss Combined Fleet**: Boss mixes battleship + carrier threats.
- **Anti‑Air Importance**: Players must consider air superiority for first time.

### 5. Submarine Viability
- **Submarine‑Only Routing**: 6‑submarine fleet goes straight to boss (C‑D‑E‑H).
- **Task Synergy**: Can complete multiple tasks simultaneously (南西諸島海域制海権, 敵空母撃沈, い号作戦).
- **Resource Efficiency**: Low consumption but risk of damage from elite enemies.

### Suggested FleetMemories Implementation Options

**Option 1: Simplified World 2 Introduction** (Easier Implementation)
- **Node Count**: 5 nodes (Start → Surface → Carrier → Resource → Boss).
- **Enemy Types**: Heavy cruisers + light carriers only; skip standard carriers.
- **Routing**: Fixed linear path; ignore complex branching.

**Option 2: Full Routing Emulation** (Closer to Kancolle)
- **Node Count**: 8 nodes (as per wiki layout).
- **Branching Rules**: Implement all conditions (carrier count, battleship count, ship types, fleet size).
- **Enemy Variety**: All surface/carrier patterns with HQ scaling.
- **Resource Nodes**: Both B (steel) and E (fast‑build) with access conditions.

**Option 3: Hybrid Approach**
- **Deterministic First Clear**: Guaranteed C‑D‑E‑H route for first few sorties.
- **Branching After Tutorial**: Introduce full branching after player understands mechanics.
- **Adjustable Complexity**: Let players choose between simple (fixed) or complex (full) routing.
