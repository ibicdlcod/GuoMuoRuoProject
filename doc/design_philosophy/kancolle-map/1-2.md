# Kantai Collection Map 1-2 Design Philosophy

## Map Overview
**World 1-2: 南西諸島沖警備 (Southwest Islands Offshore Patrol)** - The second tutorial map introducing fleet composition restrictions and resource nodes.

### Purpose
- **Fleet Composition Teaching**: Introduces routing based on ship types and counts
- **Resource Node Introduction**: First appearance of resource collection nodes
- **Increased Complexity**: Slightly more challenging enemies and branching rules
- **Early Game Progression**: Builds on mechanics learned in 1-1

### Difficulty
- **Rank**: Very Easy (Second easiest map)
- **Recommended Level**: Level 5-15 ships
- **Resource Cost**: Low (1-3 battles possible)
- **Repair Cost**: Minimal to moderate damage possible

### Unlock Requirements
- **Progression**: Unlocked after clearing 1-1
- **No special requirements**: Available after 1-1 completion

## Node Layout

### Visual Structure
```
Start → Node A (Enemy Vanguard Fleet) → Branch Point
                          ↳ Node B (Resource Node) → Sortie End
                          ↳ Node C (Enemy Vanguard Fleet) → Node D (Enemy Torpedo Squadron) → Sortie End
                          ↳ Node E (Boss) → Sortie End
```
Complex branching based on fleet composition, speed, and ship counts.

### Node Details (Based on Kancolle Wiki)
1. **Node A: 敵前衛艦隊 (Enemy Vanguard Fleet)**: Initial combat encounter
   - **Type**: Combat node (always encountered)
   - **Purpose**: First battle, similar to 1-1 but with more enemy variety
   - **Branch Point**: From here, fleet proceeds based on composition rules

2. **Node B: アイテム獲得 (Resource Node)**: First resource node in the game
   - **Type**: Resource collection node
   - **Purpose**: Teaches resource collection mechanics
   - **Progression**: Ends sortie after resource collection

3. **Node C: 敵前衛艦隊 (Enemy Vanguard Fleet)**: Secondary combat encounter
   - **Type**: Combat node
   - **Purpose**: Additional combat if routing takes this path
   - **Progression**: Leads to Node D

4. **Node D: 敵水雷戦隊 (Enemy Torpedo Squadron)**: Tertiary combat encounter
   - **Type**: Combat node with stronger enemies
   - **Purpose**: More challenging combat for longer routes
   - **Progression**: Ends sortie after combat

5. **Node E: ボス敵主力艦隊 (Boss Enemy Main Fleet)**: Primary objective
   - **Type**: Boss combat node (map clear condition)
   - **Purpose**: Map completion reward and better drops
   - **Progression**: Ends sortie after combat

### Node Types
- **Combat Nodes**: A, C, D, E feature combat
- **Resource Node**: B introduces resource collection
- **Branching Complexity**: Multiple routing conditions based on fleet composition
- **Variable Length**: Sorties can be 1-3 battles long depending on routing

## Routing Rules

### Branching Conditions (Based on Kancolle Wiki "ルート分岐法則" section)
Map 1-2 introduces **composition-based routing** with multiple conditions:

**Start → Node A (Always)**
- All fleets start at Node A after sortie begins

**Node A → Branch**:
From Node A, fleet proceeds to one of:
- **Node B (Resource Node)** - Ends sortie after resource collection
- **Node C → Node D (Combat Path)** - Two additional battles
- **Node E (Boss)** - Direct to boss

**Routing Conditions** (parsed from wiki):
1. **To Node B (Resource Node)**:
   - Requires: (Destroyers + Coastal Defense Ships) exactly 4 AND fleet size ≤5
   - Otherwise random with probabilities based on fleet size

2. **To Node E (Boss)**:
   - Multiple conditions (priority order):
     a. High speed unified fleet (all ships high speed or faster)
     b. (Destroyers + Coastal Defense Ships) ≤3
     c. (Destroyers + Coastal Defense Ships) =6
     d. (Light Cruiser + Training Cruiser) =1 AND (Destroyers + Coastal Defense Ships) =5
     e. Light Cruiser exactly 1 AND Destroyers ≥4
   - If none of the above, random with 65% chance to Node E

3. **To Node C (Combat Path)**:
   - Default path when not going to B or E

**Probability Details**:
- **Node B access probability** (when conditions not met):
  - 6 ships: 40%
  - 5 ships: 50%
  - 4 ships: 60%
  - ≤3 ships: 70%

- **Node E access probability** (when random):
  - Default: 65% chance to Node E, 35% chance to Node C

### Design Intent
- **Composition Awareness**: Teaches players that ship types affect routing
- **Resource Introduction**: First resource node teaches collection mechanics
- **Strategic Choice**: Players must balance fleet composition vs. routing goals
- **Probability Layers**: Multiple probability systems introduce complexity gradually

### Special Requirements
- **Ship Type Restrictions**: Destroyer/Coastal Defense Ship counts matter
- **Speed Requirements**: High-speed unified fleet affects routing
- **Fleet Size Strategy**: Smaller fleets have higher resource node chance
- **Light Cruiser Role**: Specific light cruiser counts enable boss routing

### Fleet Considerations
- **Single Fleet**: Surface Task Force only
- **Ship Limit**: 6 ships maximum
- **Speed Matters**: High-speed ships can enable boss routing
- **Composition Planning**: Players must consider ship types for desired routing

## Enemy Analysis (Based on Kancolle Wiki "敵編成" section)

### Node A: 敵前衛艦隊 (Enemy Vanguard Fleet)
**Purpose**: Initial combat with slightly stronger enemies than 1-1.

**Patterns**:
1. **Pattern 1 (30 EXP)**: 駆逐ロ級 (Destroyer Ro-class) ×1, 駆逐イ級 (Destroyer I-class) ×1
2. **Pattern 2 (40 EXP)**: 駆逐ロ級 ×1, 駆逐イ級 ×2
3. **Pattern 3 (45 EXP)**: 軽巡ホ級 (Light Cruiser Ho-class) ×1, 駆逐イ級 ×2
4. **Pattern 4 (55 EXP)**: 軽巡ヘ級 (Light Cruiser He-class) ×1, 駆逐イ級 ×2
5. **Pattern 5 (65 EXP)**: 軽巡ヘ級 ×1, 駆逐ロ級 ×2

**Design Notes**:
- Introduces mixed enemy compositions (destroyer + light cruiser)
- EXP values: 30-65 (higher than 1-1)
- All patterns use 単縦陣 (Line Ahead) formation

### Node B: アイテム獲得 (Resource Node)
**Purpose**: Resource collection introduction.

**Rewards**:
- Ammunition: +10～20 (increments of 5)
- Drum Canisters: +2
- Daihatsu Landing Craft: +3

**Design Notes**:
- First resource node in game progression
- Teaches resource collection without combat
- Provides tangible rewards even on failed boss attempts

### Node C: 敵前衛艦隊 (Enemy Vanguard Fleet)
**Purpose**: Secondary combat similar to Node A.

**Patterns**: Same as Node A (5 patterns, 30-65 EXP)

**Design Notes**:
- Identical to Node A for consistency
- Provides combat experience when boss is not reached

### Node D: 敵水雷戦隊 (Enemy Torpedo Squadron)
**Purpose**: More challenging combat with larger enemy fleets.

**Patterns**:
1. **Pattern 1 (60 EXP)**: 軽巡ホ級 ×1, 駆逐イ級 ×3
2. **Pattern 2 (65 EXP)**: 軽巡ホ級 ×1, 駆逐ロ級 ×1, 駆逐イ級 ×2
3. **Pattern 3 (70 EXP)**: 軽巡ホ級 ×1, 駆逐ロ級 ×2, 駆逐イ級 ×1
4. **Pattern 4 (75 EXP)**: 軽巡ホ級 ×1, 駆逐ロ級 ×3
5. **Pattern 5 (80 EXP)**: 軽巡ヘ級 ×1, 駆逐ロ級 ×3
6. **Pattern 6 (85 EXP)**: 軽巡ヘ級 ×1, 駆逐ハ級 ×1, 駆逐ロ級 ×2

**Design Notes**:
- Larger enemy fleets (4 ships) increase difficulty
- EXP values: 60-85 (higher than previous nodes)
- Introduces Torpedo Squadron concept (multiple destroyers)

### Node E: ボス敵主力艦隊 (Boss Enemy Main Fleet)
**Purpose**: Map clear condition with increased challenge.

**Patterns**:
1. **Pattern 1 (60 EXP)**: 軽巡ホ級 ×1, 駆逐イ級 ×4
2. **Pattern 2 (70 EXP)**: 軽巡ヘ級 ×1, 駆逐イ級 ×4
3. **Pattern 3 (100 EXP)**: 軽巡ヘ級 ×1, 軽巡ホ級 ×1, 駆逐イ級 ×3
4. **Pattern 4 (110 EXP)**: 軽巡ヘ級 ×1, 軽巡ホ級 ×1, 雷巡チ級 (Torpedo Cruiser Chi-class) ×1, 駆逐イ級 ×2
5. **Pattern 5 (120 EXP)**: 軽巡ヘ級 ×1, 雷巡チ級 ×2, 駆逐ハ級 ×2

**Design Notes**:
- Largest enemy fleets (5 ships)
- Introduces Torpedo Cruiser enemy type (high threat)
- EXP values: 60-120 (significant jump)
- Boss patterns feature mixed compositions with escalating difficulty

### Difficulty Progression
- **Enemy Tier**: Basic destroyers → light cruisers → torpedo cruisers
- **Fleet Size**: 2 ships → 3 ships → 4 ships → 5 ships
- **EXP Values**: 30-65 → 60-85 → 60-120 (clear progression curve)
- **Threat Level**: Moderate but introduces new enemy types

## Resource Nodes

### Node B: First Resource Node
- **Type**: Ammunition collection
- **Amount**: 10-20 ammunition (5 increments)
- **Bonus Items**: Drum canisters (+2), Daihatsu landing craft (+3)
- **Design Purpose**: Introduce resource collection without combat pressure

### Resource Collection Mechanics
- **No Combat**: Resource nodes have no enemy encounters
- **Immediate Reward**: Resources added instantly upon node completion
- **Sortie End**: Resource nodes typically end the sortie
- **Teaching Value**: Shows players that not all nodes are combat

## Drop Analysis (Based on Kancolle Wiki "ドロップ" section)

### Drop Tiers by Node
- **Node A (Vanguard Fleet)**: Basic destroyers (睦月型, 吹雪型, 綾波型, etc.) + light cruisers (天龍, 神通, 那珂)
- **Node C (Vanguard Fleet)**: Same as Node A
- **Node D (Torpedo Squadron)**: Expanded destroyer pool + light cruisers (天龍, 多摩, 木曾) + rare drops
- **Node E (Boss)**: Best drops including aircraft carrier (祥鳳), light cruisers (球磨, 多摩, 北上, 木曾), destroyers (吹雪, 白雪, 初雪, etc.)

### Design Patterns
- **Progressive Unlocks**: Better ships available at later nodes
- **Boss Incentive**: Significantly better drops encourage boss attempts
- **Resource Node No Drops**: Resource nodes don't drop ships (teaching distinction)
- **Early Game Roster Building**: Common destroyers and light cruisers help new players

### Notable Drops
- **Common**: Various destroyer classes
- **Uncommon**: Light cruisers (天龍, 龍田, 川内型, 球磨型)
- **Rare**: Aircraft carrier (祥鳳), Torpedo cruisers (北上, 木曾)
- **Seasonal**: Event ships may appear during special campaigns

## Design Patterns Observed

### Tutorial Progression from 1-1 to 1-2
1. **Increased Complexity**: 3 nodes → 5 nodes with branching options
2. **New Mechanics**: Resource nodes introduced
3. **Composition Rules**: Ship types now affect routing
4. **Speed Awareness**: High-speed fleet requirement introduced
5. **Enemy Variety**: New enemy types (Torpedo Cruiser) and larger fleets

### Adaptive Routing System
- **Multiple Conditions**: Layered priority system for routing decisions
- **Probability Layers**: Fleet size affects resource node chance, composition affects boss chance
- **Strategic Choice**: Players must decide between resource collection vs. boss attempts
- **Controllable Factors**: Fleet composition and speed are player-controlled variables

### Resource Node Design
- **Low-Risk Introduction**: First resource node has no combat
- **Tangible Reward**: Even failed sorties provide resources
- **Teaching Moment**: Distinguishes combat vs. resource nodes
- **Early Game Benefit**: Helps new players with resource accumulation

### Enemy Progression Design
- **Gradual Difficulty**: Enemy count increases gradually (2→3→4→5)
- **New Enemy Types**: Torpedo Cruiser introduced at boss node
- **EXP Scaling**: Clear progression curve (30→120)
- **Formation Consistency**: All nodes use Line Ahead for simplicity

### Psychological Design
- **Success Assurance**: Multiple paths provide some reward (resources or EXP)
- **Strategic Satisfaction**: Composition planning leads to desired routing
- **Learning Through Experimentation**: Players can test different fleets to understand rules
- **Reward Visibility**: Clear EXP progression and resource rewards
