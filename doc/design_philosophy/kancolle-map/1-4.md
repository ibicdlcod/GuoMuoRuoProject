# Kantai Collection Map 1-4 Design Philosophy

## Map Overview
**World 1-4: 南西諸島防衛線 (Southwest Islands Defense Line)** - Known as the "first gate" in Kancolle play, introducing enemy aircraft carriers (light carriers), air superiority mechanics, and complex route branching with both north and south routes.

### Purpose
- **Air Superiority Introduction**: First appearance of enemy aircraft carriers requiring air power management
- **Complex Route Branching**: Multiple branching conditions based on ship types and counts
- **Strategic Fleet Composition**: Players must balance combat power, routing requirements, and air superiority
- **Risk-Reward Tradeoffs**: Different routes offer varying difficulty and resource opportunities
- **Submarine Tender Strategy**: Special routing for submarine tenders to avoid difficult nodes

### Difficulty
- **Rank**: Moderate (☆☆☆ difficulty rating)
- **Recommended Level**: Level 15-30 ships
- **Resource Cost**: Moderate to High (3-4 battles)
- **Repair Cost**: Significant damage possible due to light carriers and battleships
- **Air Power Requirement**: Maximum enemy air power 20 (requires 60 for air superiority)

### Unlock Requirements
- **Progression**: Unlocked after clearing 1-3
- **No special requirements**: Available after 1-3 completion

### Node Types
- **Combat Nodes**: B, D, H, I, J, L feature combat (light cruisers, heavy cruisers, light carriers, battleships)
- **Resource Nodes**: C (steel), G (bauxite) introduce resource collection with equipment bonuses
- **Non-Combat Nodes**: A, E, F, K provide routing flexibility
- **Complex Branching**: Multiple conditional routing with both north (E-H-L) and south (G-J-K/L) routes

## Routing Rules

### Branching Conditions (Based on Kancolle Wiki "ルート分岐法則" section)
Map 1-4 features **complex composition-based routing** with probabilistic branches and priority-based conditions:

#### Start → First Node
- **Random (no bias)**: 50% Node A, 50% Node B
- **No composition conditions**: Pure random selection

#### Node B → Second Node
- **To Node D (强制)**: If any of:
  - Carrier-type (空母系) ≥3 ships
  - Battleship-type (戦艦級) ≥3 ships
  - (Destroyers + Coastal Defense Ships) = 0 ships
- **To Node C (强制)**: If (Destroyers + Coastal Defense Ships) ≥3 ships
- **To Node C (80% bias)**: If fleet contains Light Cruiser (軽巡級)
- **Otherwise**: Random with 60% bias toward Node C

#### Node D → Third Node
- **To Node E (强制)**: If fleet contains Submarine Tender (潜水母艦)
- **To Node G (强制)**: If fleet contains Seaplane Tender (水母)
- **Otherwise**: Random (no bias) between Node E and Node G

#### Node E → Fourth Node
- **Fixed to Node H**: No conditions

#### Node F → Fourth Node
- **To Node E (强制)**: If (Destroyers + Coastal Defense Ships) ≥4 ships
- **To Node E (强制)**: If (Destroyers + Coastal Defense Ships) ≥2 ships AND (Seaplane Tender + Submarine Tender + Supply Ship) ≥1 ship OR Aviation Battleship ≥2 ships
- **To Random E/H (biased)**: If (Destroyers + Coastal Defense Ships) ≥2 ships
  - 3 ships: 80% bias to Node E
  - 2 ships: 60% bias to Node E
- **Otherwise**: Random (no bias) between Node H and Node I

#### Node J → Final Node
- **To Node L (强制)**: If Light Cruiser ≥1 AND Seaplane Tender ≥1 AND (Destroyers + Coastal Defense Ships) ≥2
- **To Node L (强制)**: If Destroyers ≥4 ships
- **To Node L (75% bias)**: If Destroyers ≥2 ships
- **Otherwise**: Random with 65% bias toward Node L

### Priority System
Conditions are evaluated in priority order (top to bottom in wiki table). First matching condition determines route.

### Design Intent
- **Carrier/Battleship Penalty**: High carrier or battleship counts force difficult route (B→D)
- **Destroyer Emphasis**: Many destroyers help reach favorable routes (B→C, F→E)
- **Submarine Tender Strategy**: Submarine tenders provide route control (D→E fixed)
- **Seaplane Tender Routing**: Seaplane tenders force southern route (D→G)
- **Air Superiority Challenge**: Enemy carriers require air power management
- **Strategic Composition**: Players must carefully balance ship types for optimal routing

### Fleet Considerations
- **Single Fleet**: Surface Task Force only
- **Ship Limit**: 6 ships maximum
- **No locking**: Ships not locked to this map
- **Strategic Composition**: Players must balance combat power, routing goals, and air superiority

## Enemy Analysis (Based on Kancolle Wiki "敵編成" section)

### Node B/D: 敵偵察艦隊 (Enemy Scout Fleet)
**Purpose**: Initial combat encounter teaching light cruiser/heavy cruiser compositions.

**Patterns** (All use 単縦陣 or 複縦陣 - Line Ahead or Double Line):
1. **Pattern 1 (90 EXP)**: 軽巡ヘ級 (Light Cruiser He-class) ×2 + 駆逐ハ級 (Destroyer Ha-class) ×2
2. **Pattern 2 (90 EXP)**: 重巡リ級 (Heavy Cruiser Ri-class) ×1 + 軽巡ヘ級 ×1 + 駆逐ロ級 (Destroyer Ro-class) ×2
3. **Pattern 3 (90 EXP)**: 重巡リ級 ×1 + 軽巡ヘ級 ×1 + 駆逐イ級 (Destroyer I-class) ×3

**Design Notes**:
- Consistent 90 EXP across all patterns
- Introduces heavy cruiser (リ級) in patterns 2-3
- Mixed formations teach target priority

### Node H: 敵前衛任務部隊I軍 (Enemy Vanguard Task Force I)
**Purpose**: Northern route combat introducing light carriers and air power mechanics.

**Patterns** (All use 輪形陣 - Circular Formation):
1. **Pattern 1 (110 EXP)**: 軽母ヌ級 (Light Carrier Nu-class) ×2 + 軽巡ヘ級 ×1 + 駆逐ロ級 ×2
   - **Air Power**: 16 (優勢: 24, 確保: 48)
2. **Pattern 2 (120 EXP)**: 軽母ヌ級 ×2 + 重巡リ級 ×1 + 軽巡ヘ級 ×1 + 駆逐ロ級 ×2
   - **Air Power**: 16 (優勢: 24, 確保: 48)
3. **Pattern 3 (130 EXP)**: Same as Pattern 2
   - **Air Power**: 16 (優勢: 24, 確保: 48)

**Design Notes**:
- First appearance of enemy aircraft carriers (軽母ヌ級)
- Air power values require player air superiority planning
- Circular formation reduces enemy accuracy but increases durability
- EXP progression: 110 → 130 with increasing threat

### Node I: 敵前衛任務部隊II群 (Enemy Vanguard Task Force II)

### Difficulty Progression
- **Enemy Tier**: Light/heavy cruisers → Light carriers → Battleship + carrier combination
- **Air Power**: 0 (B/D) → 14-16 (H/I) → 20 (J) → 24 (L) (clear air power curve)
- **Fleet Size**: 4 ships (B/D) → 5 ships (H/I) → 5-6 ships (J/L)
- **EXP Values**: 90 → 100-130 → 150-200 → 220-270 (clear power curve)
- **Threat Level**: Moderate → High → Very High → Extreme (battleship+carrier)

## Resource Nodes

### Node C: Steel Collection
- **Base Amount**: Steel +10~20 (increments of 5)
- **Equipment Bonuses**:
  - Drum Canisters: +1.5 steel per slot
  - Daihatsu-type landing craft: +2 steel per slot
- **Strategic Importance**: Early steel collection teaches transport equipment mechanics

### Node G: Bauxite Collection
- **Base Amount**: Bauxite +10~20 (increments of 5)
- **Equipment Bonuses**: Same as Node C
- **Access Condition**: Requires southern route (D→G) with seaplane tender or random chance

### Design Purpose
- **Resource Type Introduction**: First bauxite collection node in game
- **Equipment Bonus Teaching**: Transport equipment increases resource gain
- **Route-Specific Resources**: Different resources on different routes encourage exploration
- **Strategic Choice**: Players choose between combat route (north) and resource route (south)

## Drop Analysis (Based on Kancolle Wiki "ドロップ" section)

### Drop Tiers by Node
- **Node B/D (Scout Fleet)**: Common destroyers and light cruisers (睦月型, 吹雪型, 暁型, 初春型, 白露型, 陽炎型)
- **Node H/I (Vanguard Task Force)**: Expanded light cruiser pool + heavy cruisers (古鷹, 加古, 青葉, 妙高, 那智, 足柄, 羽黒)
- **Node J (Main Fleet)**: Premium ships including light carriers (鳳翔, 龍驤, 祥鳳) and rare destroyers (巻雲, 朝霜)
- **Node L (Boss)**: Best drops including all above plus potential event-limited ships

### Design Patterns
- **Progressive Unlocks**: Better ships available at later nodes (boss-only drops)
- **Air Power Rewards**: Carrier nodes drop carriers, encouraging air superiority builds
- **Boss Incentive**: Premium ships (carriers, rare destroyers) encourage boss attempts
- **Farming Strategy**: Players can farm Node H/I for heavy cruisers if boss is difficult

### Notable Drops
- **Common**: Various destroyer classes and light cruisers
- **Uncommon**: Heavy cruisers, light carriers
- **Rare**: 龍驤 (light carrier), 祥鳳 (light carrier), 巻雲 (destroyer), 朝霜 (destroyer)
- **Event Drops**: Seasonal/event ships may appear during limited periods

- **Submarine Tender Strategy**: Specialized routing provides alternative strategy

### Psychological Design
- **"First Gate" Challenge**: Known as significant difficulty spike in early game
- **Carrier Intimidation**: First enemy carriers create memorable challenge
- **Routing Mastery**: Learning optimal compositions provides sense of progression
- **Risk-Reward Balance**: Southern route offers resources but harder combat

### Farming Mechanics
- **Resource Farming**: Node C/G for steel/bauxite with transport equipment
- **Carrier Farming**: Node H/I for light carrier drops
