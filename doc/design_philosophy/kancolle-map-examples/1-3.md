# Kantai Collection Map 1-3 Design Philosophy

## Map Overview
**World 1-3: 製油所地帯沿岸 (Refinery Area Coastal Waters)** - The third tutorial map introducing heavy cruisers, battleships, whirlpool mechanics, and complex composition-based routing.

### Purpose
- **Advanced Fleet Composition Teaching**: Introduces routing based on ship types (carriers, battleships, supply ships, seaplane tenders, aviation cruisers)
- **Whirlpool Introduction**: First appearance of whirlpool (うずしお) nodes that drain fuel
- **Resource Farming**: Multiple resource nodes for fuel collection
- **Increased Challenge**: First appearance of heavy cruisers and battleships as enemies
- **Strategic Depth**: Complex routing with multiple viable fleet compositions

### Difficulty
- **Rank**: Easy to Moderate (☆☆ difficulty rating)
- **Recommended Level**: Level 10-25 ships
- **Resource Cost**: Moderate (2-3 battles + potential fuel loss/gain)
- **Repair Cost**: Moderate damage possible due to heavy cruiser/battleship enemies

### Unlock Requirements
- **Progression**: Unlocked after clearing 1-2
- **No special requirements**: Available after 1-2 completion

   - **Purpose**: Routing decision point based on fleet composition

   - **Type**: Non-combat node
   - **Purpose**: Connects resource node to combat path

4. **Node D: アイテム獲得 (Resource Node)**: Fuel collection node
   - **Type**: Resource collection node
   - **Purpose**: Teaches resource collection with transport equipment bonuses
   - **Resource**: Fuel +10~20 (increments of 5)
   - **Equipment Bonuses**: Drum Canisters (+2), Daihatsu-type (+3)

5. **Node E: 敵前衛艦隊 (Enemy Vanguard Fleet)**: Secondary combat encounter
   - **Type**: Combat node
   - **Purpose**: Additional combat for non-carrier routes
   - **Progression**: Leads to Node F (support fleet)

6. **Node F: 敵支援艦隊 (Enemy Support Fleet)**: Mid-map combat encounter
   - **Type**: Combat node
   - **Purpose**: Introduces heavy cruiser enemies (リ級)
   - **Progression**: Major routing decision point to Whirlpool (H) or Boss (J)

7. **Node G: アイテム獲得 (Resource Node)**: Secondary fuel collection node
   - **Type**: Resource collection node
   - **Purpose**: Additional resource collection opportunity
   - **Resource**: Fuel +10~30 (increments of 5)
   - **Equipment Bonuses**: Drum Canisters (+2), Daihatsu-type (+3)

8. **Node H: うずしお (Whirlpool)**: Fuel loss node
   - **Type**: Hazard node
   - **Purpose**: Introduces whirlpool mechanics and fuel management
   - **Effect**: Loses 24% or 90% of current fuel (reduced by radar equipment)

9. **Node I: 戦闘なし (No Combat)**: Alternative node after whirlpool
   - **Type**: Non-combat node
   - **Purpose**: Safe exit from whirlpool route
   - **Progression**: Ends sortie

10. **Node J: ボス敵主力艦隊 (Boss Enemy Main Fleet)**: Primary objective
    - **Type**: Boss combat node (map clear condition)
    - **Purpose**: Map completion reward and better drops
    - **Progression**: Ends sortie after combat

### Node Types
- **Combat Nodes**: C, E, F, J feature combat (light cruisers, heavy cruisers, battleships)
- **Resource Nodes**: D, G introduce fuel collection with equipment bonuses
- **Hazard Node**: H introduces whirlpool fuel loss mechanic
- **Non-Combat Nodes**: A, B, I provide routing flexibility
- **Complex Branching**: Multiple conditional routing based on exact fleet composition

## Routing Rules

### Branching Conditions (Based on Kancolle Wiki "ルート分岐法則" section)
Map 1-3 features **composition-based routing** with multiple conditional branches:

#### Start → First Node
- **To Node A**: If fleet contains Supply Ship OR Seaplane Tender
- **To Node C**: If fleet contains Carrier-type (any carrier)
- **Otherwise**: Random (no bias) between A and C

#### Node A → Second Node
- **To Node D (Resource)**: If fleet contains Supply Ship OR 4+ Coastal Defense Ships
- **To Node D (80% bias)**: If fleet contains Seaplane Tender OR (Destroyers + Coastal Defense Ships) ≥4
- **To Node E (Combat)**: If fleet contains Submarine
- **Otherwise**: Random (no bias) between D and E

#### Node F → Third Node
- **To Node H (Whirlpool)**: If fleet contains Regular Carrier OR (Slow) Battleship
- **To Node J (Boss)**: If any of:
  - Aviation Cruiser ≥1 AND Destroyers ≥2
  - Destroyers ≥4
  - (Light Cruiser + Training Cruiser) ≥1 AND (Destroyers + Coastal Defense Ships) ≥4
  - High Speed Unified fleet (all ships high speed or faster) → J-biased random
- **Otherwise**: Random with bias toward H

#### Node H → Fourth Node
- **To Node G (Resource)**: If fleet contains Supply Ship
- **To Node J (Boss)**: If fleet contains Seaplane Tender OR Aviation Cruiser OR (Light Cruiser + Training Cruiser) ≥1 AND Destroyers ≥2
- **To Random (I low chance)**: If Destroyers ≥2
- **Otherwise**: Random between I and J with bias toward I

### Priority System
Conditions are evaluated in priority order (top to bottom in wiki table). First matching condition determines route.

### Design Intent
- **Carrier/Battleship Penalty**: Regular carriers and slow battleships force whirlpool route (H)
- **Resource Access**: Supply ships guarantee resource nodes (D, G)
- **Destroyer Emphasis**: Many destroyers help reach boss (J) from F and H
- **Composition Awareness**: Players must carefully consider ship types and counts
- **Risk-Reward**: Whirlpool route (H) offers potential boss access but with fuel loss

### Fleet Considerations
- **Single Fleet**: Surface Task Force only
- **Ship Limit**: 6 ships maximum
- **No locking**: Ships not locked to this map
- **Strategic Composition**: Players must balance combat power, routing goals, and resource management

## Enemy Analysis (Based on Kancolle Wiki "敵編成" section)

### Node C: 敵前衛艦隊 (Enemy Vanguard Fleet)
**Purpose**: Initial combat for carrier-containing fleets.

**Patterns** (All use 単縦陣 - Line Ahead):
1. **Pattern 1 (50 EXP)**: 軽巡ホ級 (Light Cruiser Ho-class) ×1 + 駆逐イ級 (Destroyer I-class) ×2
2. **Pattern 2 (60 EXP)**: 軽巡ホ級 ×1 + 駆逐ロ級 (Destroyer Ro-class) ×2
3. **Pattern 3 (70 EXP)**: 軽巡ホ級 ×1 + 駆逐ハ級 (Destroyer Ha-class) ×2
4. **Pattern 4 (70 EXP)**: 軽巡ヘ級 (Light Cruiser He-class) ×1 + 駆逐ロ級 ×2
5. **Pattern 5 (70 EXP)**: 軽巡ヘ級 ×1 + 駆逐ハ級 ×2
6. **Pattern 6 (80 EXP)**: Same as Pattern 5
7. **Pattern 7 (90 EXP)**: 軽巡ヘ級 ×1 + 駆逐ハ級 ×1 + 駆逐ロ級 ×2

**Design Notes**:
- Light cruiser + destroyer compositions similar to 1-1/1-2 but with higher EXP
- Introduces 軽巡ヘ級 (He-class) variant with pattern 4-7
- EXP progression: 50 → 90 with pattern variations

### Node E: 敵前衛艦隊 (Enemy Vanguard Fleet)
**Purpose**: Secondary combat for non-carrier routes.

**Patterns** (All use 単縦陣 - Line Ahead):
1. **Pattern 1 (50 EXP)**: 軽巡ホ級 ×1 + 駆逐イ級 ×2
2. **Pattern 2 (60 EXP)**: 軽巡ホ級 ×1 + 駆逐ロ級 ×2
3. **Pattern 3 (70 EXP)**: 軽巡ホ級 ×1 + 駆逐ハ級 ×2
4. **Pattern 4 (70 EXP)**: 軽巡ヘ級 ×1 + 駆逐ロ級 ×2
5. **Pattern 5 (70 EXP)**: 軽巡ヘ級 ×1 + 駆逐ハ級 ×2
6. **Pattern 6 (80 EXP)**: Same as Pattern 5
7. **Pattern 7 (90 EXP)**: 軽巡ヘ級 ×1 + 駆逐ハ級 ×1 + 駆逐ロ級 ×2

**Design Notes**:
- Identical to Node C patterns (same enemy types and EXP)
- Provides consistent challenge regardless of route

### Node F: 敵支援艦隊 (Enemy Support Fleet)
**Purpose**: Introduces heavy cruiser enemies with higher threat.

**Patterns** (Uses 単縦陣 or 複縦陣 - Line Ahead or Double Line):
1. **Pattern 1 (65 EXP)**: 重巡リ級 (Heavy Cruiser Ri-class) ×1 + 駆逐イ級 ×3
2. **Pattern 2 (90 EXP)**: 重巡リ級 ×1 + 駆逐ロ級 ×3
3. **Pattern 3 (100 EXP)**: 重巡リ級 ×1 + 雷巡チ級 (Torpedo Cruiser Chi-class) ×1 + 駆逐ロ級 ×2
4. **Pattern 4 (110 EXP)**: 重巡リ級 ×2 + 駆逐ロ級 ×2

**Design Notes**:
- First appearance of heavy cruisers (リ級) - significantly higher firepower
- Introduces torpedo cruisers (チ級) in pattern 3
- EXP values: 65 → 110 with increasing threat
- Mixed formations teach target priority (focus heavy cruisers first)

### Node J: ボス敵主力艦隊 (Boss Enemy Main Fleet)
**Purpose**: Map clear condition with battleship introduction.

**Patterns** (Uses 単縦陣 or 複縦陣 - Line Ahead or Double Line):
1. **Pattern 1 (130 EXP)**: 戦艦ル級 (Battleship Ru-class) ×1 + 軽巡ヘ級 ×1 + 駆逐イ級 ×3
2. **Pattern 2 (140 EXP)**: 戦艦ル級 ×1 + 雷巡チ級 ×1 + 軽巡ヘ級 ×1 + 駆逐イ級 ×2
3. **Pattern 3 (150 EXP)**: 戦艦ル級 ×1 + 雷巡チ級 ×1 + 軽巡ヘ級 ×1 + 駆逐ロ級 ×2

**Design Notes**:
- First appearance of battleships (ル級) - high armor and firepower
- Battleships introduce "forced second shelling phase" mechanic
- Mixed fleet requires strategic target selection
- EXP progression: 130 → 150 (significant jump from previous nodes)
- Boss patterns feature 5 ships total, requiring stronger player fleets

### Difficulty Progression
- **Enemy Tier**: Light cruisers/destroyers → Heavy cruisers → Battleships
- **Fleet Size**: 3 ships (C/E) → 4 ships (F) → 5 ships (J)
- **EXP Values**: 50-90 → 65-110 → 130-150 (clear power curve)
- **Threat Level**: Moderate → High → Very High (battleship introduction)

## Resource Nodes

### Node D: Fuel Collection
- **Base Amount**: Fuel +10~20 (increments of 5)
- **Equipment Bonuses**:
  - Drum Canisters: +2 fuel per slot
  - Daihatsu-type landing craft: +3 fuel per slot
- **Strategic Importance**: Early fuel collection teaches transport equipment mechanics

### Node G: Fuel Collection  
- **Base Amount**: Fuel +10~30 (increments of 5)
- **Equipment Bonuses**: Same as Node D
- **Access Condition**: Requires passing through whirlpool (Node H) with supply ship

### Whirlpool (Node H): Fuel Loss
- **Base Loss**: 24% or 90% of current fuel (two possible strengths)
- **Radar Mitigation**: Each radar equipped reduces loss percentage
  - 0 radar: -24%/-90%
  - 6 radar: -9.6%/-36% (maximum reduction)
- **Design Purpose**: Teaches resource management and radar utility
- **Risk-Reward**: Whirlpool route can lead to boss but with fuel penalty

## Drop Analysis (Based on Kancolle Wiki "ドロップ" section)

### Drop Tiers by Node
- **Node C/E (Vanguard Fleet)**: Light cruisers (多摩, 木曾, 川内, 神通, 那珂) + various destroyers
- **Node F (Support Fleet)**: Expanded light cruiser pool (長良, 五十鈴, 名取, 由良) + same destroyers
- **Node J (Boss)**: Premium ships including:
  - **Carriers**: 鳳翔 (light carrier)
  - **Heavy Cruisers**: 古鷹, 加古, 青葉, 衣笠
  - **Light Cruisers**: Expanded pool including 天龍, 龍田, 球磨, 北上
  - **Destroyers**: Full early-game roster
  - **Seaplane Tenders**: 千歳, 千代田, 瑞穂
  - **Rare Drops**: Seasonal/event ships may appear

### Design Patterns
- **Progressive Unlocks**: Better ships available at later nodes (boss-only drops)
- **Early Game Roster Building**: Common destroyers and light cruisers help new players
- **Boss Incentive**: Premium ships (carriers, heavy cruisers) encourage boss attempts
- **Farming Strategy**: Players can farm Node F for specific light cruisers if boss is difficult

### Notable Drops
- **Common**: Various destroyer classes and light cruisers
- **Uncommon**: Heavy cruisers, seaplane tenders
- **Rare**: Light carrier 鳳翔, seasonal/event ships

## Design Patterns Observed

### Tutorial Progression Elements
1. **Mechanical Introduction**: Whirlpool (fuel loss), radar mitigation, transport equipment bonuses
2. **Enemy Tier Progression**: Light cruisers → Heavy cruisers → Battleships (clear power curve)
3. **Composition Awareness**: Multiple routing conditions teach ship type importance
4. **Resource Management**: Fuel collection vs. loss trade-offs

### Strategic Depth
- **Multiple Viable Routes**: Different fleet compositions enable different strategies
- **Risk-Reward Balance**: Whirlpool route offers boss access with fuel penalty
- **Equipment Importance**: Radar reduces whirlpool loss, transport equipment increases resource gain
- **Fleet Building**: Players must consider both combat effectiveness and routing requirements

### Psychological Design
- **Challenge Scaling**: Battleship introduction provides significant but manageable challenge
- **Progression Feeling**: Clear enemy tier advancement from previous maps
- **Player Agency**: Multiple composition options allow personalized strategies
- **Learning Through Failure**: Whirlpool fuel loss teaches consequences without permanent damage

### Farming Mechanics
- **Resource Farming**: "三重クル" (Mie Kur) technique uses Node D for efficient fuel farming
- **Boss Access Control**: Composition choices determine boss chance
- **Drop Optimization**: Different nodes offer different ship pools for targeted farming
