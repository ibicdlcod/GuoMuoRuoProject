# Kantai Collection Map 2-2 Design Philosophy

## Map Overview
**World 2‑2: バシー海峡 (Bashi Channel)** – Focuses on transport‑ship hunting and bauxite gathering, with battleship‑heavy enemy compositions and complex routing influenced by ship‑type combinations.

### Purpose
- **Transport‑Ship Hunting**: Primary map for completing “supply‑ship destruction” daily/weekly tasks (ろ号作戦).
- **Bauxite‑Gathering**: Features dedicated bauxite resource nodes (A: +10‑20, F: +15‑35).
- **Battleship Introduction**: Enemy battleships appear in non‑boss nodes (G: 戦艦ル級).
- **Complex Routing**: Multiple branching points with intricate ship‑type/count conditions.
- **Task Synergy**: Allows simultaneous completion of multiple tasks (南西諸島海域制海権, 敵空母撃沈, い号作戦).

### Difficulty
- **Rank**: ☆☆☆☆ (Medium‑High – battleships in non‑boss nodes increase threat)
- **Recommended Fleet**: Mixed fleets with seaplane tenders, light carriers, destroyers.
- **Resource Cost**: Moderate (2‑4 combat nodes depending on route).
- **Repair Cost**: Medium‑High (battleship nodes can cause heavy damage).
- **Special Mechanics**: Bauxite resource nodes, transport‑ship farming, complex routing.

### Unlock Requirements
- **Progression**: Unlocked after clearing 1‑4 and 2‑1.
- **Requirements**: Must clear 1‑4 “南西諸島防衛線” and 2‑1 “南西諸島近海”.

## Routing Rules

### Branching Conditions (Based on “ルート分岐法則” section)
Rules are evaluated top‑down; first matching condition applies.

#### Start → C/B Branch (Initial)
| Branch Point | Destination | Condition |
|--------------|-------------|-----------|
| **Start** → **C** | **B** | Fleet contains **≥3 carriers** (any type). |
| | **B** | Fleet contains **≥2 aviation battleships**. |
| | **B** | Fleet contains **≥1 supply ship AND 0 submarines**. |
| | **B/E Random** | Fleet contains **≥1 aviation battleship** AND **≥1 seaplane tender/submarine tender** → 70% B, 30% E. |
| | **B/D Random** | **All other cases** → 70% B, 30% D. |
| **Start** → **E** | **E** | Fleet contains **≥1 seaplane tender/submarine tender**. |
| | **D/E Random** | **All other cases** → 50% D, 50% E. |

#### E → F/G/K Branch (After C‑E)
| Condition | Destination |
|-----------|-------------|
| Fleet contains **≥4 ships among (battleships + carriers)** | **G** |
| Fleet contains **≥2 coastal defense ships** | **F** |
| Fleet contains **3 ships among (battleships + carriers)** | **G/K Random** (70% G, 30% K). |
| Fleet contains **2 ships among (battleships + carriers)** | **G/K Random** (50% G, 50% K). |
| Fleet contains **1 ship among (battleships + carriers)** | **G/K Random** (30% G, 70% K). |
| Fleet contains **≥3 destroyers/coastal defense ships** AND **≥1 submarine tender** | **F** |
| Fleet contains **≥2 destroyers/coastal defense ships**: |
| – AND **≥1 light cruiser** AND **all ships fast (高速以上統一)** | **K** |
| – **All other cases** | **F/K Random** (70% K, 30% F). |
| **All other cases** | **G/K Random** (50% G, 50% K). |

#### G → H Branch (After C‑E‑G)
| Condition | Destination |
|-----------|-------------|
| Fleet contains **≥1 carrier** (any type) | **H** |
| Fleet contains **0 destroyers** | **H** |
| **All other cases** | **Random**. |

#### K → H/I Branch (After C‑E‑K)
| Condition | Destination |
|-----------|-------------|
| Fleet contains **≥4 ships among (battleships + carriers)** | **I/K Random** (I‑biased). |
| Fleet contains **≥1 ship among (carriers + aviation cruisers + seaplane tenders)** | **K** |
| Fleet contains **≥1 submarine** | **I/K Random** (I‑biased). |
| Fleet contains **≥2 destroyers/coastal defense ships** | **J/K Random**. |
| Fleet contains **1 destroyer/coastal defense ship** | **Random**. |
| **All other cases** | **I/K Random**. |

#### J → K Branch (After C‑E‑K‑J)
Fixed to K (boss).

### Design Intent
- **Transport‑Ship Farming**: West routes (B/A, D/B) provide reliable transport‑ship encounters for task completion.
- **Bauxite‑Focused Routes**: F node offers substantial bauxite, encouraging resource‑gathering play.
- **Battleship/Carrier Penalty**: Heavy fleets (≥4 battleships/carriers) forced to G (battleship node).
- **Light‑Fleet Optimization**: Fleets with 1 light cruiser + 4‑5 destroyers (all fast) get optimal routing to boss.
- **Coastal‑Defense Niche**: ≥2 coastal defense ships guarantee F route (bauxite resource).

### Ship‑Classification Notes
- “軽巡級” = light cruisers + training cruisers **+ torpedo cruisers**.
- “空母系” = all carriers (standard, armored, light).
- “戦艦級” = battleships (fast + slow) + aviation battleships.
- “水母” = seaplane tenders.
- “潜水母艦” = submarine tenders.
- “補給艦” = supply ships (includes special‑duty ships, icebreakers, etc.).
- “海防艦” = coastal defense ships (includes “海防戦艦” like Norge).

**HQ‑Level Scaling**:
- **HQ < 80**: Patterns 1‑3 only (weakened).
- **HQ 80‑119**: Patterns 1‑5 (partial elite).

**Design Notes**: Boss progresses from light‑carrier to standard‑carrier to battleship‑carrier combinations.

### Difficulty Progression
- **Enemy Tier**: Transports → torpedo cruisers → battleships → carrier‑battleship combined fleet.
- **EXP Values**: 100‑130 (E) → 150‑220 (B/D) → 150‑180 (G) → 160‑220 (K).
- **Formations**: Surface nodes use 単縦/複縦, carrier nodes use 輪形.
- **Threat Level**: Transport nodes relatively safe; battleship node (G) dangerous; boss escalates with HQ level.

## Resource Nodes

- **Bauxite**: +10, +15, or +20 (5‑step increments)
- **Additional**: Drum cans +1.5×3, large‑landing‑craft series +2

- **Bauxite**: +15, +20, +25, +30, or +35 (5‑step increments)
- **Additional**: Drum cans +1.5×5, large‑landing‑craft series +2
- **Access**: Requires ≥2 coastal defense ships or specific routing

### Node J: Fast‑Build Material Acquisition
- **Fast‑Build Material**: +1
- **Access**: Specific routing conditions (destroyer/coastal defense heavy fleets)

### Design Intent
- **Bauxite‑Focused Economy**: Major bauxite source for carrier‑heavy fleets.
- **Transport‑Ship Farming**: West routes optimized for task completion with resource bonus.
- **Strategic Choice**: Players choose between resource gathering (bauxite) vs efficient boss routing.

## Design Patterns Observed

### 1. Transport‑Ship Hunting Focus
- **Dedicated Transport Nodes**: B and D nodes feature 2‑3 transport ships each.
- **Task Efficiency**: One sortie can yield 2 transport kills (daily task requires 3).
- **Resource Bonus**: Transport routes also provide bauxite, creating economic incentive.

### 2. Bauxite‑Gathering Economy
- **Substantial Bauxite Rewards**: Up to +35 bauxite per sortie at F node.
- **Carrier‑Friendly**: Bauxite supports carrier‑heavy fleet operations.
- **Strategic Routing**: Coastal‑defense ships (≥2) guarantee bauxite route.

### 3. Battleship in Non‑Boss Node
- **Early Battleship Introduction**: Node G features battleships before boss.
- **Routing Penalty**: Heavy fleets (≥4 battleships/carriers) forced to G.
- **Risk‑Reward**: Battleship node offers higher EXP but greater damage risk.

### 4. Complex Conditional Routing
- **Multiple Branch Points**: Start (C/B), E (F/G/K), G (H), K (H/I/J).
- **Ship‑Count Dependencies**: Different rules based on exact counts of battleships/carriers.
- **Speed Requirements**: “All fast” condition for optimal routing.
- **Coastal‑Defense Niche**: Special routing for coastal defense ships.

### 5. Task Synergy Design
- **Multi‑Task Completion**: Can simultaneously work on:
  - 南西諸島海域制海権 (Southwest Sea Control)
  - 敵空母撃沈 (Carrier Sink)
  - い号作戦 (Operation I‑Go)
  - ろ号作戦 (Transport‑Ship Destruction)
- **Efficient Farming**: West route (B/A) perfect for transport‑ship tasks.

## Implementation Notes for FleetMemories

### Adaptation Considerations
1. **Transport‑Ship Mechanics**: Implement transport ships as distinct enemy type with task‑tracking.
2. **Bauxite Resource System**: Add bauxite as collectible resource with variable amounts.
3. **Complex Routing**: Implement multiple branching with ship‑count‑specific conditions.
4. **Non‑Boss Battleships**: Add battleship enemies to intermediate nodes.
5. **Task Integration**: Link map completion to multiple task systems.

### Suggested FleetMemories Implementation Options

**Option 1: Simplified Transport‑Hunting Map** (Easier Implementation)
- **Node Count**: 6 nodes (Start → Transport → Resource → Surface → Boss).
- **Enemy Types**: Transports + light cruisers; skip battleships in non‑boss nodes.
- **Routing**: Fixed linear path; ignore complex branching.
- **Resource Nodes**: Single bauxite node.
- **Task Focus**: Optimized for transport‑ship destruction tasks.

**Option 2: Full Routing Emulation** (Closer to Kancolle)
- **Node Count**: 11 nodes (as per wiki layout).
- **Branching Rules**: Implement all conditions (ship type/count, coastal defense, speed).
- **Enemy Variety**: All transport/surface/battleship/carrier patterns.
- **Resource Nodes**: Multiple bauxite nodes with access conditions.
- **Task Synergy**: Support simultaneous task progress tracking.

**Option 3: Hybrid Approach**
- **Transport‑Farming Mode**: Special route guaranteed for transport‑ship hunting tasks.
- **Boss‑Rush Mode**: Optimized route for map clearing.
- **Resource‑Gathering Mode**: Route focused on bauxite collection.
- **Player Choice**: Let players select primary objective before sortie.

### Map Design Principles to Emulate
1. **Task‑Focused Design**: Create maps that efficiently support specific player tasks.
2. **Resource‑Combat Balance**: Reward resource gathering with combat penalties (longer routes).
3. **Ship‑Type Niches**: Give specialized ships (coastal defense, seaplane tenders) unique routing advantages.
4. **Progressive Threat Introduction**: Introduce new enemy types (battleships) in non‑boss nodes first.
5. **Economic Gameplay**: Support resource‑gathering as valid playstyle.
