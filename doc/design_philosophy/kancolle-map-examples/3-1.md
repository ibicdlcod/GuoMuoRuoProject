# Kantai Collection Map 3-1 Design Philosophy

## Map Overview
**World 3-1: モーレイ海哨戒 (Morey Sea Patrol)** - A 4-star difficulty introduction to World 3 (Northern Waters) focusing on fleet composition balance, resource node mechanics, and progressive difficulty increase from World 2.

### Purpose
- **World 3 Introduction**: First map of Northern Waters, introducing colder climate themes and new enemy types
- **Resource Management**: Ammunition-focused resource node with scaling yields based on equipment
- **Composition Balance Test**: Teaches players to balance battleship/carrier counts with lighter ships
- **Progressive Difficulty**: Moderate 4-star difficulty bridge between World 2 and more challenging Northern Waters maps
- **Early Northern Waters Farming**: Accessible farming for mid-game ships and resources

### Difficulty
- **Rank**: ☆☆☆☆ (4 stars)
- **Recommended Level**: Level 40-60 ships
- **Resource Cost**: Moderate fuel/ammo consumption
- **Repair Cost**: Manageable damage at combat nodes
- **EXP Range**: 130-200 (boss node 180-200)
- **HQ Level Scaling**: Not explicitly mentioned, but enemy patterns may scale

### Unlock Requirements
- **Prerequisite**: Clear World 2-4 ("beginner's wall")
- **Progression Gate**: Requires mastery of World 2 mechanics before Northern Waters access

## Route Branching Rules (ルート分岐法則)

### Key Class Definitions
- **戦艦級 (Battleship-class)**: Fast Battleships, (Slow) Battleships, Aviation Battleships
- **空母系 (Carrier-type)**: Standard Carriers, Armored Carriers, Light Carriers
- **軽巡級 (Light Cruiser-class)**: Light Cruisers, Training Cruisers, **Torpedo Cruisers** (updated 2022/11/13)
- **重巡級 (Heavy Cruiser-class)**: Heavy Cruisers, Aviation Cruisers
- **水母 (Seaplane Tender)**: Seaplane Tenders
- **補給艦 (Replenishment Ships)**: Fleet Oilers, Special Duty Ships, etc.
- **海防艦 (Coastal Defense Ships)**: Coastal Defense Ships

### Detailed Branching Conditions (Priority: Higher conditions take precedence)

**C → B/D/F**
- **(Destroyer + Coastal Defense) ≤1** → D
- **(Aviation Battleship + Light Cruiser + Seaplane Tender + Replenishment) ≥3**:
  - **(Battleship-class + Carrier-type) ≥3** → Random B/D
  - **Otherwise** → Random B/F
- **(Seaplane Tender + Replenishment) ≥1 AND (Destroyer + Coastal Defense) ≥3** → Random B/F
- **Submarine ≥3** → Random D/F
- **(Battleship-class + Carrier-type) ≥3** → D
- **Otherwise** → F

**D → E/F/G**
- **(Battleship-class + Carrier-type) ≥5** → E
- **Submarine =6** → E
- **Submarine Tender =1 AND Submarine =5** → G
- **Otherwise** → F

**F → G**
- **Fixed** → G (boss)

### Strategic Implications
**Three Main Route Groups**:
1. **Heavy Fleet Route**: C→D→E/F→? (requires ≥3 BB/CV, faces carrier node D)
2. **Mixed Fleet Route**: C→B/F→? (moderate composition, may hit resource node)
3. **Light Fleet Route**: C→F→G (default route, avoids heavy combat nodes)

**Key Design Elements**:
- **Submarine Routing**: Submarine-heavy fleets (≥3) get random routing, encouraging submarine use but with uncertainty
- **Heavy Ship Penalty**: Battleship/carrier heavy fleets (≥3) routed to D node with carrier combat
- **Resource Node Access**: Requires specific compositions to reach node A (ammunition)
- **Default Boss Route**: Light fleets default to F→G, providing accessible boss path for newer players

**Educational Intent**: Teaches that heavy fleets face tougher enemies (carrier node D), while balanced compositions have more predictable routing.

## Design Philosophy Analysis

### Role in Game Progression
**Northern Waters Introduction**: First map of World 3, introducing players to colder climate themes and increased difficulty after World 2.

**Composition Balance Reinforcement**: Continues teaching from World 2-4 that balanced fleets perform better than heavy battleship/carrier spam.

**Resource Mechanic Expansion**: First map with significant equipment-based resource yield scaling (Drum Canisters, Landing Craft).

**Progressive Difficulty Curve**: 4-star difficulty provides manageable increase from World 2's 6-star "wall" (2-4).

### Strategic Intent
**Equipment Utility Demonstration**: Drum Canisters and Landing Craft increase resource yields, teaching players to equip non-combat items.

**Fleet Diversity Encouragement**: Submarine routing (random) encourages experimentation with different fleet types.

**Predictable Routing for New Players**: Default light fleet route (C→F→G) provides accessible boss path while heavier fleets face tougher challenges.

**Carrier Introduction**: Node D introduces light carrier enemies, preparing players for more carrier-heavy maps later.

### Notable Design Features
**Equipment-Based Resource Scaling**: First map where equipment significantly affects resource node yields, teaching long-term optimization.

**Submarine Routing Mechanics**: Random routing for submarine-heavy fleets introduces uncertainty vs. power trade-off.

**Progressive Enemy Types**: Introduces Ri-class heavy cruisers and Nu-class light carriers as new enemy types.

**Accessible Boss Path**: Default route allows newer players to reach boss with moderate fleets.

**Moderate Air Power Requirements**: 28 maximum air power at boss is manageable for mid-game players.

### Map-Specific Mechanics
**Route-Based Trade-offs**:
- **Heavy Route**: More combat, carrier node, potentially more rewards
- **Light Route**: Fewer combats, direct boss access, less resource gathering

**Resource Optimization**: Drum Canisters and Landing Craft provide tangible benefits, encouraging equipment strategy beyond combat.

**Submarine Viability**: Submarines work but with routing uncertainty, teaching risk-reward assessment.

### Overall Design Goal
A balanced introduction to World 3 that reinforces composition lessons from World 2 while introducing new mechanics (equipment-based resource scaling, submarine routing). Provides accessible farming for mid-game ships while preparing players for more challenging Northern Waters maps.

The map serves as a skill check: players who mastered World 2 mechanics will find it manageable, while those relying on heavy fleets will face tougher challenges. It bridges the gap between beginner and intermediate play.

## Implementation Considerations for FleetMemories

### Core Mechanics to Replicate
1. **Composition-Based Routing**: Heavy fleets (≥3 BB/CV) routed to tougher nodes
2. **Equipment-Based Resource Scaling**: Drum Canisters/Landing Craft increase ammunition yields
3. **Submarine Routing**: Submarine-heavy fleets get random routing
4. **Progressive Enemy Types**: Introduce Ri-class heavy cruisers and Nu-class light carriers
5. **Accessible Default Route**: Light fleets get straightforward boss path

### Adaptation Suggestions
1. **Simplify Routing Complexity**: Reduce number of branching conditions while maintaining strategic choices
2. **Adjust Resource Values**: Scale ammunition yields to FleetMemories' economy
3. **Modify Enemy Types**: Use equivalent enemy types from FleetMemories' roster
4. **Maintain Educational Intent**: Keep the "balanced fleet" lesson through routing restrictions
5. **Preserve Equipment Utility**: Ensure non-combat equipment provides meaningful benefits

### Balance Considerations
- **Difficulty Curve**: Position as manageable increase after World 2-4
- **Resource Economy**: Make ammunition yields meaningful but not game-breaking
- **Enemy Strength**: Ensure enemy difficulty matches mid-game progression
- **Route Viability**: Ensure all routes remain viable with different player resources

### Learning Objectives to Preserve
1. **Equipment Matters**: Non-combat equipment affects resource gathering
2. **Fleet Balance**: Heavy fleets face tougher challenges
3. **Submarine Trade-offs**: Submarines provide power but routing uncertainty
4. **Resource Planning**: Equipment optimization affects long-term resource gains
