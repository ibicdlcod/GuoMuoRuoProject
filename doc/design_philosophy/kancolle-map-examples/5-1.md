# Kantai Collection Map 5-1 Design Philosophy
## 南方海域進出作戦 (Southern Waters Advance Operation)

### Map Overview
**Purpose:** Introduction to Southern Waters, teaching players to choose between light fleet and battleship‑heavy fleet compositions.

**Difficulty:** ☆☆☆☆☆☆☆☆ (8 stars) – moderately difficult, requires proper fleet building.

**Unlock Requirements:**
- Clear map 3‑4 (北方海域全域) – though some reports indicate alternative unlock conditions
- Teaches progression from Northern to Southern waters

**Notable Features:**
- **Two distinct routing paths:** Light fleet (north route) vs. battleship‑heavy fleet (south/central route)
- **Resource nodes:** Steel (C), Ammo (H), Whirlpool (A) with fuel drain
- **ASW node without visual effect:** Node E consumes fuel (5‑8%) but no ammo
- **Carrier‑heavy enemy nodes:** D (aircraft carrier mobile force) and J (boss) require air power consideration

**BGM Changes:**
- Map: "艦隊の再集結"
- Route daytime: "華の二水戦（インストVer.）"
- Route night: "夜戦"
- Boss daytime/night: "全艦娘、突撃！"

### Node Layout
Map features **10 combat nodes** (A–J) plus start point, with clear north/south split.

**Key Node Types:**
- **Start → A/B** (branch based on fleet composition)
- **A** – **Whirlpool** (うずしお) – fuel drain
- **B** – Surface combat (敵南方前衛哨戒艦隊)
- **C** – **Resource (Steel)** +25‑50 steel, bonus with drums/landing craft
- **D** – Carrier‑based enemy (敵南方空母機動部隊)
- **E** – **ASW (no visual effect)** (敵潜水艦南方哨戒線) – fuel consumption only
- **F** – Surface combat (敵南方任務部隊 B群)
- **G** – Surface combat (敵南方任務部隊 A群)
- **H** – **Resource (Ammo)** +45‑70 ammo
- **I** – No combat (敵影を見ず)
- **J** – **Boss** (敵南方前線司令艦隊)

**Route Structure:**
```
North Route (Light Fleet): Start → B → C → F → J (3 combat nodes)
South/Central Route (Heavy Fleet): Start → A → D/E → G → J (4 combat nodes)
```

### Routing Rules (ルート分岐法則)
**Updated:** 2020‑03‑18

**Key Branching Conditions:**

1. **Start → A/B:**
   - **A if:** (Battleship‑class + Carrier‑type) ≥5
   - **B if:** (Battleship‑class + Carrier‑type) ≤2 **AND** Destroyer ≥2
   - **B if:** Heavy cruiser‑class ≥4 **AND** Light cruiser ≥1
   - **B if:** Heavy cruiser‑class ≥2 **AND** Light cruiser =1 (exactly)
   - **B‑biased random (75%) if:** Battleship‑class =3 **AND** Light cruiser =1 **AND** Destroyer =2
   - **Otherwise random**

2. **C → E/C:**
   - **E if:** Contains regular carrier **OR** Light carrier ≥2 **OR** Light cruiser =1 (exactly)
   - **C if:** Battleship‑class ≤2 **OR** Destroyer ≥2
   - **Otherwise random?**

3. **F → G/H/J:**
   - **H if:** (Light cruiser + Destroyer) =0 **OR** (Battleship‑class + Light carrier) ≥4
   - **Random if:** (Battleship‑class + Light carrier) =3
   - **J if:** Fastest unified (note: not high‑speed or high‑speed+, but fastest)
   - **If Light cruiser ≥1:**
     - **J if:** Destroyer ≥2
     - **G otherwise**
   - **J if:** Destroyer ≥4
   - **Random G/J (J‑biased) if:** Destroyer =3
   - **Random G/J (G‑biased) if:** Destroyer =2
   - **G if:** Destroyer =1

4. **G → I/J:**
   - **I if:** (Battleship‑class + Carrier‑type) ≥5
   - **Random if:** Carrier‑type ≥1 **AND** (Battleship‑class + Carrier‑type) ≥3 **OR** contains submarine
   - **J if:** High‑speed+ unified
   - **If Heavy cruiser‑class ≥4:**
     - **J? if:** (Battleship‑class + Carrier‑type + Torpedo cruiser) =0
     - **J‑biased random otherwise**
   - **I‑biased random if:** Contains regular carrier
   - **J if:** Destroyer ≥4 **OR** (Heavy cruiser‑class ≥2 **AND** Destroyer ≥2) **OR** (Light cruiser ≥1 **AND** Destroyer ≥2)
   - **J‑biased random (85%) if:** Battleship‑class =3 **AND** Light cruiser =1 **AND** Heavy cruiser‑class =2
   - **Otherwise I‑biased random**

**Speed Notes:**
- **Fastest unified:** All ships at fastest speed (requires turbines/boilers)
- **High‑speed+ unified:** All ships at high‑speed+ or faster
- Speed enhancements reference: [速力](/kancolle/%E9%80%9F%E5%8A%9B)

### Resource Nodes
**C – Steel Collection:**
- Base: +25‑50 steel (increments of 5)
- **Bonus equipment:** Drum cans (+2), Landing craft types (+3)
- Strategic value: Encourages transport equipment for resource farming

**H – Ammo Collection:**
- +45‑70 ammo (likely increments of 5)
- Provides ammunition replenishment before boss

**A – Whirlpool (Fuel Drain):**
- **Base loss:** 30% fuel
- **Radar mitigation:** Each radar multiplicatively reduces loss
- **Maximum loss unconfirmed** – may be capped
- **Design intent:** Penalize radar‑poor fleets, encourage equipment optimization

### Design Patterns Observed

#### 1. **Dual‑Path Fleet Specialization**
- **North route (B‑C‑F‑J):** Light fleet (destroyer‑heavy, limited battleships/carriers)
- **South/Central route (A‑D/E‑G‑J):** Battleship‑heavy fleet
- **Teaching moment:** Players must choose fleet composition based on available ships and strategy

#### 2. **Carrier‑Focused Enemy Design**
- Node D features **6 pattern progression** with increasing air power
- **Pattern 6** has extreme air power (573 fighter power) – teaches importance of fighter coverage
- Boss patterns 4‑5 introduce carrier‑based boss fleets

#### 3. **ASW Without Visual Effect**
- Node E consumes fuel but not ammo, with no submarine visual effect
- Teaches players that ASW nodes can have hidden mechanics
- Fuel‑only consumption unique among early maps

#### 4. **Resource Node Bonuses**
- Steel node C rewards transport equipment (drums, landing craft)
- Encourages players to equip resource‑gathering gear
- Provides tangible benefit for dedicated resource farming

#### 5. **Speed‑Based Routing**
- **Fastest unified** requirement for certain branches (not just high‑speed)
- Introduces speed enhancement mechanics (turbines, boilers)
- Requires careful speed tuning for optimal routing

#### 6. **Boss Composition Variance**
- Surface‑heavy patterns (1‑3) vs. carrier‑heavy patterns (4‑5)
- Forces players to prepare balanced fleets capable of handling both
- Carrier patterns require significant fighter investment

#### 7. **Mission‑Driven Design**
- Multiple quests require specific fleet compositions (三川艦隊, 水上打撃部隊, etc.)
- Encourages repeated engagement with different fleet builds
- Provides long‑term goals beyond simple clearance

### Implementation Notes for FleetMemories

#### **Routing System**
- Implement **dual‑path branching** based on ship composition counts
- Support **exact ship count conditions** (e.g., "light cruiser =1 exactly")
- Calculate **speed categories:** fastest, high‑speed+, high‑speed, etc.
- Handle **biased random branching** with percentage weights

#### **Enemy Fleet Design**
- **Node D:** Implement 6‑pattern progression with escalating air power
- **Boss node:** Alternate between surface‑heavy and carrier‑heavy compositions
- **ASW node E:** Special fuel‑only consumption, no visual effect
- **Resource nodes:** Bonus mechanics for transport equipment

#### **Resource Mechanics**
- **Whirlpool fuel drain:** Implement radar mitigation formula
- **Steel collection:** Bonus with drum cans (+2) and landing craft (+3)
- **Ammo collection:** Simple replenishment before boss

#### **Player Guidance**
- Clearly explain **north vs. south route requirements**
- Highlight **carrier threat** at node D and boss patterns 4‑5
- Teach **speed enhancement mechanics** for routing optimization
- Note **ASW node peculiarities** (fuel‑only consumption)

#### **Quest Integration**
- Design quests requiring specific historical fleet compositions
- Balance difficulty for quest‑specific fleet restrictions
- Provide appropriate rewards for quest completion

#### **Difficulty Balancing**
- Maintain **8‑star difficulty** through route‑specific challenges
- Ensure **carrier patterns** are challenging but not impossible
- Balance **resource costs** against map rewards
- Provide **clear progression** from Northern to Southern waters

### Conclusion
Map 5‑1 serves as an effective introduction to Southern Waters, teaching players to specialize their fleet composition for specific routing paths. The dual‑route design encourages strategic thinking, while the carrier‑heavy nodes emphasize air power importance. The map successfully introduces new mechanics like speed‑based routing, resource node bonuses, and ASW without visual effects, preparing players for more complex Southern Waters maps.

For FleetMemories, this map provides a template for dual‑path design, carrier‑focused enemy composition, and resource node mechanics with equipment bonuses.
