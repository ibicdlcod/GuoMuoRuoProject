# Kantai Collection Map 6-5 Design Philosophy
**Operation Carrier Task Force Interception** (空母機動部隊迎撃戦)

## Map Overview
- **Purpose**: High‑difficulty combined‑fleet engagement focusing on carrier‑heavy enemy forces; tests LBAS coordination and night‑battle target selection
- **Difficulty**: ☆☆☆☆☆☆☆ (7 stars), very high
- **Unlock Requirements**: **6‑4 clear AND Land‑Based Air Support (LBAS) unlocked**
- **HP Gauge**: **Combined Fleet (連合艦隊編成)** – 12 ships total (main + escort). Boss flagship sink reduces gauge by ⅙ (16.7%); 6 sinks required
  - **Gauge reduction only occurs when 空母棲姫 (Carrier Princess) is sunk**
  - If night‑battle sink, must nearly wipe escort fleet before shelling phase to target main fleet
- **Monthly Rewards**: **Medal ×1** + **Special War Results +250** (time‑limited to end of month)
  - **Special War Results deadline**: month‑end 21:59
  - **Medal deadline**: month‑end 23:59
  - After deadline, gauge resets on re‑login (clear mark disappears)
- **Land‑Based Air Support (LBAS)**: Usable (2 squadrons); base air raids occur (1 raid, lower route may have 0‑1 raids)
  - **Air raids stop after gauge destruction**
  - Required radius to boss: **5**
- **Dynamic Enemy Scaling**: Enemy compositions change based on **remaining HP gauge percentage**
- **Historical Context**: Simulates interception of enemy carrier task force at KW Atoll (KW環礁沖海域)

## Routing Rules
**Key Branching Conditions**:

### Start → A/B
- **To A** if ANY of:
  - **0 light cruisers** (軽巡級)
  - **Carrier‑type (空母系) OR Torpedo Cruiser (雷巡) included**
  - **4+ Battleship‑type** (戦艦級)
- **Otherwise B** (submarine node)

### B → B (fixed)

### C → C/F
- **To C** if ANY of:
  - **3+ Battleship‑type**
  - **≤1 destroyer**
- **Otherwise F**

### F → D/E
- **To E** if ANY of:
  - **0 destroyers**
  - **2+ Torpedo Cruisers**
  - **(Battleship‑type + Carrier‑type) ≥4**
  - **(Battleship‑type + Carrier‑type + Heavy Cruiser‑type) ≥5**
- **Otherwise D**

### D → H/I
- **To H** if fleet contains **Carrier‑type AND Light Cruiser AND Destroyer**
- **Otherwise I**

### I → H/J
- **To H** if **0 light cruisers**
- **To J** if **2+ destroyers**
- **To J** if ALL of:
  - **0 Battleship‑type**
  - **(Carrier‑type + Heavy Cruiser‑type) ≤4**
  - **Carrier‑type ≤2**
  - **Heavy Cruiser‑type ≤4**
- **Otherwise H**

### J → K/M
- **To K** if **LoS insufficient**
- **To M** if **LoS score ≥50** (HQ 120, branch coefficient 3)

### G → K/M
- **To L** if **LoS insufficient**
- **To M** if **LoS score ≥35?** (HQ 120, branch coefficient 3)

**LoS Notes**:
- **Branch coefficient**: **3** (high)
- LoS scores listed for HQ 120; lower HQ need +1 margin
- LoS calculation uses standard formula (索敵スコア計算式)

## Design Patterns Observed
1. **Combined‑Fleet Boss**: First map in World 6 with 12‑ship combined fleet, teaching players to manage two fleets simultaneously
2. **Monthly Time‑Limited Rewards**: Medal and Special War Results create urgency and encourage early‑month clearing
3. **Carrier‑Focused Interception**: Enemy compositions heavily feature carriers (空母棲姫, 空母ヲ級flagship) requiring strong anti‑air and carrier‑kill capability
4. **Dynamic Gauge Scaling**: Enemy strength adapts to remaining HP, rewarding efficient clears and punishing drawn‑out campaigns
5. **Submarine/Air‑Raid Resource Drain**: Multiple resource‑draining nodes (B, E, G, H, J) force players to manage fuel/ammo reserves carefully
6. **LoS‑Gated Boss Access**: High LoS requirements (coefficient 3) ensure players equip adequate reconnaissance
7. **Night‑Battle Target Selection**: Night‑battle sink mechanics require strategic damage distribution between escort and main fleets
8. **LBAS Coordination Requirement**: Two LBAS squadrons and radius‑5 requirement emphasize base air support as core strategy
9. **Post‑Clear Pattern Weighting**: Boss patterns shift to 60%/40% distribution after gauge clear, maintaining farming challenge
10. **Progressive Light Cruiser/Destroyer Threat**: Node A shows gradual enemy upgrade from イ級→ロ級→ハ級後期型, teaching destroyer tier recognition
