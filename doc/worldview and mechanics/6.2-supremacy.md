# Naval Supremacy

Each map have a naval supremacy value which ranges from 0% to 300% (it's -1% when you have not unlocked them)

Successfully defeating the BOSS node in a normal map sets its naval supremacy value to at least 100%/200%/300% (for Early-war/Mid-war/Late-war difficulties S rank, multiplied by 0.8 if A rank and 0.5 if B rank).

Naval supremacy will decay by [rule/navalsupremacydecay](settings.md) multiplied by your current naval supremacy each minute (don't apply when server is down).

You are not allowed to play Mid-war/Late-war difficulty unless you already have 90%/180% naval supremacy there by playing Early-war/Mid-war difficulty.

### Resource gain

[This image](../map/map_resources.svg) describes the relation between land resources. For each land resource node, the average naval supremacy in related naval map will grant you appropriate percentage of resources in that land.

## Normal Expedition

As you are only sortieing one map at the same time, it's not practical to maintain naval supremacy by normal sortieing. Instead you can send a weaker expedition fleet to automatically fight for you, 15 minutes per node.

Expedition fleet does not have to fight BOSS node to maintain naval supremacy. Successfully completing any end node (an empty one don't count) in a normal map sets its naval supermacy value to $a/2+40\%$/$a/2+80\%$/$a/2+120\%$ (Early-war/Mid-war/Late-war difficulties, the fixed part modified by 0.8x for A victory and 0.5x for B victory) where $a$ is your current naval supremacy. The calculated value will have no effect if this value is lower than the supremacy you already have.
