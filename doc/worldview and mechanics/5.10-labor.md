# Labor condition[NOTYETIMPLEMENTED]

It is not beneficial to use the same ships 24/7.

Each ship have a condition capped at 480 that will change by -5 per battle node (further +1 for S-victory, 0 for A-victory (and further -1 for each rank worse), -1 for night battle for day-battle-start nodes or day battle for night-battle-start nodes) when you send them on sortie/expedition. If done by sortie(not expedition), the condition will only start to recover after 15 minutes (scaled to 60 if 0% HP) of rest. They recover by 1 per 3 minutes.

No flagship or MVP condition bonus is planned.

Condition above 60 is displayed green, above 36 and below 144 is yellow, and below 36 is red.

If the condition drops to below 0, ALL your kanmusu will start losing experience as they hate you for overworking their brethren. This only applies to sortie though; if anyone in an expedition fleet have their condition drop to 0 the fleet will stop.
