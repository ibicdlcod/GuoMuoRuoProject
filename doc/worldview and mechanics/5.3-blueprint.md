# Ship blueprint

A crucial difference of this game from KC is you no longer instantly get ship drops after battle. Instead you get ship blueprints of each different ship and each different remodel level. Then you need to combine the blueprint and initial equipment to construct ships. As in previously mentioned, at the start of game you get a destroyer for your home port so you can have a ship to battle and gain more ship blueprints.

## Drop rule

[Implemented in Server::drop]

Kantai collection battle nodes have a uniform drop probability resulting in an exponential distribution of work needed to get a rare drop. This is considered very unfair and this game offers a revised distribution of work needed to get a rare drop.

The server, for each account and each ship, calculates a drop value. (This initial value never goes below 0). This means the server knows in advance how long it takes to drop a ship blueprint (this value should not be publicized).

A drop value of 1000 does not always mean you need to win the boss 1000 times to get a blueprint though. Each battle node have a list of weights. If the weight is 0, the ship blueprint is not dropped here and you have to find elsewhere. If the weight is 10, you on average have to battle 100 times to get the blueprint. (This means S rank; if A rank then for this specific battle the weight is multiplied by 0.8 and B rank 0.5)

On each battle won, the drop value decreases according to weight. Then among rare drops, one random ship that have drop value reached 0 or lower get dropped. If no such ship exists, then among common drops, the ship that have lowest drop value get dropped (ties are broken randomly).
