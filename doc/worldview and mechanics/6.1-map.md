# Map

There are 86 normal maps in the base game, spanning all over the globe. Unlike in KC, maps are not grouped into sea zones.

Normal maps have three difficulty tiers: Early-war, Mid-war and Late-war.

## Battle nodes [NOTIMPLEMENTED]

Each map have a network of battle nodes with branching rules similar to KC. Unlike in KC there are no resource nodes, as clearing map itself will grant regeneration of resources. 

## Map relations [NOTIMPLEMENTED]

[This image](../map/map.svg) describes the relation between maps. An edge means when you pass a map, you unlock the map at the other side when your fleet have ships of appropriate nationality (see below).

At the start of the game you unlock your [home port](5.2-homeport.md).

| Edge color | [Appropriate nationality](../ship/shipidexplanation.md) |
| ---------- | ------------------------------------------------------- |
| Red        | Japanese(0x100000)/Chinese(0x800000)                    |
| Grey       | German(0x200000)/Nordic(0xA00000)                       |
| Green      | Italian(0x300000)                                       |
| Blue       | American(0x400000)                                      |
| Orange     | British(0x500000)                                       |
| Dark Blue  | French(0x600000)                                        |
| Dark Red   | Soviet(0x700000)                                        |
| Cyan       | Oceanian(0xB00000)                                      |
