# Cloning

[Implemented in Server::doConstruct#possess_limit]

Cloning allows a player to construct a second (or further) copy of a ship they already own, at the cost of **sanity** — an exotic resource that regenerates slowly over time. Cloning is performed via the **Cloning Vats** factory mode, which shares factory slots with ordinary construction.

Remodelling an existing ship is unaffected by the cloning system.

## Sanity cost

[Implemented in ResExotic]

The sanity cost of the $n$-th clone (where $n \geq 1$ is the number of ships in the remodel group already owned before the clone is started) is:

$$\text{Cost} = 2^{n-1}$$

The first clone costs 1 sanity, the second costs 2, the third costs 4, and so on. See [resources](3-resources.md#sanity-regeneration) for regeneration details.

## Level requirement

[Implemented in Server::doConstruct#cloning_level_check]

To place the $n$-th clone into production, the player must own at least one ship in the same remodel group whose **effective level** (capped exp converted via `Ship::getLevel`, including KC exp from `UserKCShip`) exceeds $n \times 100$:

$$\text{level}_{\max} > n \times 100$$

This means the 1st clone requires an existing ship above level 100, the 2nd above level 200, and so on. Reaching level 101+ requires at least one decoration — see [decoration](5.11-decoration.md).

## Fleet restriction

[Implemented in Server::updateFleet#check_duplicate_remodel_group]

Two ships from the same remodel group may not be assigned to the same fleet. Clones are intended to serve in different theatres of war simultaneously.
