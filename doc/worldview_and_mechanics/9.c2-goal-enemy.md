# Tactical goal (against enemy fleet)

Also called "Enemy Fleet Priority", this attribute affect your battle primarily through your attack against enemies.

| Goal                   | Explantion                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ignore submarines      | Ignore submarines when there are still surface ships                                                                                                                                                                                                                                                                                                       |
| Balanced               | All ships will attempt to attack targets that are large but not too large that it cannot penetrate.<br/>That is, all ships (excluding submarines) that have [capitalness](5.1-capitalness.md) $x$ will prioritize ships that have capitalness $x-2, x-1, x$.<br/> Submarines won't be affected, and prioritizes everyone, and are prioritized by everyone. |
| Focus on capital ships |                                                                                                                                                                                                                                                                                                                                                            |
| Focus on screen        |                                                                                                                                                                                                                                                                                                                                                            |
| Focus on land          |                                                                                                                                                                                                                                                                                                                                                            |
| Focus on sea           |                                                                                                                                                                                                                                                                                                                                                            |
| Focus on flagship      |                                                                                                                                                                                                                                                                                                                                                            |
| Focus on non-flagship  |                                                                                                                                                                                                                                                                                                                                                            |
| Random                 |                                                                                                                                                                                                                                                                                                                                                            |

There is also **night battle control** that admiral will send to his/her fleet; beware low LOS and/or ship speed may cause your control to fail; that is, night battle occurs when you don't want it, or it does not occur when you want it.

| Goal                               | Explantion                                                       |
| ---------------------------------- | ---------------------------------------------------------------- |
| Night battle                       | Always                                                           |
| Night battle when losing           | Night battle when result is at/below C                           |
| Night battle when flagship remains | Can be combined with other night battle goals, with OR condition |
| Strive for rank A                  | Night battle when result is at/below B                           |
| Strive for rank S                  | Night battle when result is at/below A                           |
