# Tactical goal (against enemy fleet)

This attribute affect your battle primarily through your attack against enemies.

| Goal                   | Explantion                                                                                        |
| ---------------------- | ------------------------------------------------------------------------------------------------- |
| Ignore submarines      | Ignore submarines when there are still surface ships                                              |
| Balanced               | All ships will attemp to attack targets that are large but not too large that it cannot penetrate |
| Focus on capital ships |                                                                                                   |
| Focus on screen        |                                                                                                   |
| Focus on land          |                                                                                                   |
| Focus on sea           |                                                                                                   |
| Focus on flagship      |                                                                                                   |
| Focus on non-flagship  |                                                                                                   |

There is also night battle control that admiral will send to his/her fleet; beware low LOS and/or ship speed may cause your control to fail; that is, night battle occurs when you don't want it, or it does not occur when you want it. (The fail chance never exceeds 50% to prevent abuse)

| Goal                               | Explantion                                                       |
| ---------------------------------- | ---------------------------------------------------------------- |
| Night battle                       |                                                                  |
| Night battle when losing           |                                                                  |
| Night battle when flagship remains | Can be combined with other night battle goals, with OR condition |
| Strive for rank A                  | Night battle when result is at/below B                           |
| Strive for rank S                  | Night battle when result is at/below A                           |
