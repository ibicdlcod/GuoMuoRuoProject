# Naval Supremacy

Each map have a naval supremacy value which ranges from 0% to 300% (it's -1% when you have not unlocked them)

[Implemented in Server::processBattle#gain_supremacy] Successfully defeating the BOSS node in a normal map sets its naval supremacy value to 100%/200%/300% (for Early-war/Mid-war/Late-war difficulties S rank, multiplied by 0.8 if A rank and 0.5 if B rank). The calculated value will have no effect if this value is lower than the supremacy you already have.

[Implemented in Server::minutePulse#decrease_supremacy] Naval supremacy will decay by 1/([rule/navalsupremacydecay](settings.md)) multiplied by your current naval supremacy each minute (don't apply when server is down).

[Implemented in User::isMapUnlocked] You are not allowed to play Mid-war/Late-war difficulty unless you already have 90%/180% naval supremacy there by playing Early-war/Mid-war difficulty.

### Resource gain

[Implemented in Server::minutePulse#regen_resources_based_on_supremacy] [This image](../map/map_resources.svg) describes the relation between land resources.

Land maps (in reality, resource virtual maps) have id greater than 1024, while sea maps (and map's unionid, denoted by MapWithDiff::getUnionId) does not have this property.

For each land resource virtual map, the average naval supremacy in each related (relations are 'RS' entries in [Map_relations.csv](../map/Map_relations.csv)) coastal naval map will grant you appropriate percentage of resources in that land (detailed in [Map_nodes.csv](../map/Map_nodes.csv)) every 1000 (more precisely [rule/mapresourcecontrol](settings.md)) minutes divided by total coastal map related by that land.

[Implemented in Client::demandResourceGain, Client::loadResourceMaps] The resource gain display in the client is computed entirely client-side using [Map_nodes.csv](../map/Map_nodes.csv) base values and [Map_relations.csv](../map/Map_relations.csv) RS edges loaded at startup, combined with the cached `mapSupremacies`. No server round-trip is required. **Warning:** the displayed gain figures will be nonsensical if the client-side CSV files do not match the copies used by the server (e.g. after a server update that changes resource values before the client has received updated files).

## Normal Expedition

[Implemented in ExpeditionManager] As you are only sortieing one map at the same time, it's not practical to maintain naval supremacy all over the globe by normal sortieing. Instead you can send a weaker expedition fleet to automatically fight for you, 15 minutes per node.

Expedition fleet does not have to fight BOSS node to maintain naval supremacy. Successfully completing any end node (an empty one don't count) in a normal map sets its naval supremacy value to $(\frac{a}{2}+40)\%$/$(\frac{a}{2}+80)\%$/$(\frac{a}{2}+120)\%$ (Early-war/Mid-war/Late-war difficulties, the fixed part modified by 0.8x for A victory and 0.5x for B victory) where $a$ is your current naval supremacy. The calculated value will have no effect if this value is lower than the supremacy you already have.
