# Night-battle-start node

A **night-battle-start node** (`isNightCommence = true`) enters battle directly
into the night battle phase, skipping the day phases (air battle, approaching,
central, disengaging). This represents map nodes where the player fleet
initiates combat under cover of darkness.

[Implemented in Battle::battleProcessor, Battle::nightBattle]

## Phase flow

1. Night battle commences with `clock = 0`
2. Night-capable planes start unloaded; first air attack delayed by cooldown
3. Main gun reloading begins; ships with higher enemy LOS are more likely to
   start unloaded (probability = `losE / hypot(max(1,losE), max(1,losF))`)
4. Torpedo attacks, secondary guns, and air reload events fire during the
   30-second night battle phase
5. **Extra battle decision** at phase end (see below)

## Extra battle decision

The extra battle decision logic is shared with day-battle-start nodes via
`Battle::decideExtraBattle()`. The same algorithm runs regardless of whether
the battle started at day or night:

| Condition | Effect |
|-----------|--------|
| Either fleet fully sunk | `extraBattle = false`, returns retreat time `y` |
| Player wants + enemy wants | `extraBattle = true`, duration = 20s |
| Neither wants | `extraBattle = false`, duration = `y` |
| Player wants + enemy doesn't | Duration = `(20-y)·x + y`, pursuit chance = `x` |
| Enemy wants + player doesn't | Duration = `(20-y)·(1-x) + y`, pursuit chance = `1-x` |

Where:
- $x = \min(1, \frac{\text{speed}_F}{\max(1,\text{speed}_E)} \cdot \frac{\text{LOS}_F}{\max(1,\text{LOS}_F + \text{LOS}_E)})$ — player pursuit advantage
- $y = \min(20, \frac{2000}{\max(1, \sqrt{\text{speed}_E \cdot \text{speed}_F})})$ — mutual retreat time

`ourWantsExtra` is true if any `BattlePlan` flag applies given the battle assessment:
- `extraBattle = true`
- `extraBattleWhenLosing` and assessment ≥ C defeat
- `extraBattleWhenBorBelow` and assessment ≥ B victory
- `extraBattleWhenAorBelow` and assessment ≥ A victory
- `extraBattleWhenFlagship` and flagship survives

Enemy preference is a 50/50 coin flip.

## Comparison with day-battle-start

The logic is identical — both paths call `Battle::decideExtraBattle()`.
The only difference is the call site:

| Aspect | Day-battle-start | Night-battle-start |
|--------|-----------------|-------------------|
| Call site | `disengagingPhase()` | End of `nightBattle()` |
| Uses return value? | Yes — `advanceClockTime(phaseDuration)` | No — ignores duration |
