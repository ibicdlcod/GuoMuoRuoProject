# Communication efficiency

Each ship have a communication efficiency that only take into account itself and the fleet's flagship.

[Implemented in Battle::Battle#communication-init]

The probability that a ship received proper orders is

$$
p=\frac{x}{\sqrt{1+x^2}}
$$

where $x$ is communication efficiency of flagship and itself multiplied.

(However, the chance of flagshp itself receiveing proper orders always have $x=\infty$ and $p=1$)

For enemy ships, $p=0$ (meaningless) as they don't have battle plans.

## Calculation of $x$

Command-fac type of equipment boosts communication efficiency.

| Equipment ID                | Name                   | Efficiency (×equip LOS / 10) | Condition in order to be effective                                                                             |
| --------------------------- | ---------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 107                         | 艦隊司令部施設                | ×4                           | Only combined fleets' flagship                                                                                 |
| 272                         | 遊撃部隊 艦隊司令部             | ×3.2                         | Only normal fleets' flagship                                                                                   |
| 413                         | 精鋭水雷戦隊 司令部             | ×2.8                         | Only torpedo squadrons' flagship                                                                               |
| 531                         | 艦隊通信アンテナ               | ×2                           |                                                                                                                |
| 532                         | 通信装置＆要員                | ×1.6                         |                                                                                                                |
| 4098                        | 遠征艦隊 司令部               | ×2.4                         | Only expedition fleets' flagship                                                                               |
| TBD[Planned for the future] | Amnesiac signal jammer | /2.0                         | Used by advanced enemies and affects all friendly ships (formula is divided by (equip LOS / 10), not multiply) |

The above multiplier is 0.1 times the "LOS" attribute of "command-fac" type equipment.

Base value is $y=\frac{l}{\sqrt{1+l^2}}$ where $l=\text{ship level} \times a$ where a is [rule/basecommunicationefficiency](settings.md)

The end value is base value $y$ multiplied by all the multipliers.
