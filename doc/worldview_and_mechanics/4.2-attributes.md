## Attributes

Equipment have many attributes that is vital to their functions. Most of these attributes apply to ships as well, though ships have some unique ones.

|         Field          |        Equipment meaning [Implemented in equipment.h]        |             Ship meaning [Implemented in ship.h]             | Display in ShipAttrDialog                                |
| :--------------------: | :----------------------------------------------------------: | :----------------------------------------------------------: | -------------------------------------------------------- |
|          No.           |                   Equipment definition ID                    |                      Ship definition ID                      |                                                          |
|         OldNo.         |                              -                               |                Ship ID in KC (yyb is 0xb0yy)                 |                                                          |
|     OldNoInternal      |                              -                               |                      Internal ID in KC                       |                                                          |
|      Remodelstage      |                              -                               |               Remodel stage, deduced from No.                |                                                          |
|        remodel         |                              -                               |                        Remodel target                        |                                                          |
|          Uuid          |               Instance ID, varies by instance                |                            ditto                             |                                                          |
|       name/ja_JP       |                        Japanese name                         |                            ditto                             |                                                          |
|       name/zh_CN       |              Chinese name (not yet implemented)              |                            ditto                             |                                                          |
|       name/en_US       |              English name (not yet implemented)              |                            ditto                             |                                                          |
|  shipclasstext/ja_JP   |                              -                               |                     describes ship class                     |                                                          |
|  shipordertext/ja_JP   |                              -                               |                     describes ship order                     |                                                          |
|       equiptype        |                        Equipment type                        |                              -                               |                                                          |
|        shiptype        |                              -                               |                 Ship type, deduced from No.                  |                                                          |
|       shipclass        |                              -                               |                 Ship class, deduced from No.                 |                                                          |
|      nationality       |                              -                               |             Nation of the ship, deduced from No.             |                                                          |
|          種別          |                           (Unused)                           |                                                              |                                                          |
|          Tech          | Tech level (may not correspond to actual year said equipment appears, for game balance reasons) | Tech level (may not correspond to actual year said ship appears, for game balance reasons) |                                                          |
|         Rarity         |                              -                               |            Average difficulty of blueprint drops             |                                                          |
|       Allegiance       |                              -                               | Country/territory of the ship, (only that recognized in QLocale is supported) |                                                          |
|         Father         |  You must own "Father" equipment to develop this equipment   |                              -                               |                                                          |
|        Father2         |                            ditto                             |                              -                               |                                                          |
|         Mother         | You must have enough skill points at "Mother" equipment to develop this equipment (said skill points will be consumed) |                              -                               |                                                          |
|    Defaultequip1~5     |                              -                               | Equipment that you must possess to construct this ship, and will be consumed |                                                          |
| Disallowmassproduction | Maximum number of this equipment you may have (infinite if not present, -1 means production disabled) | - (you need to specifically clone ships rather than construct more of them) |                                                          |
|       Equipslots       |                              -                               |                       Equipment slots                        |                                                          |
|         Planes         |                              -                               | Planes (you can freely distribute planes across your slots, unlike in KC) | yes                                                      |
|       Hitpoints        |              Equivalent to 0.1 hitpoints in KC.              |                            ditto                             | yes                                                      |
|          DPM           |  Equivalent to 0.1 firepower in KC, countered by hitpoints.  | ditto (Carrier's DPM is special as it amplifies plane's airtorpedo/bombing) | yes                                                      |
|         Armor          | Equivalent to 0.5 armor in KC, countered by armorpenetration. Have stacking penalty. |                            ditto                             | yes                                                      |
|    Armorpenetration    |                    Have stacking penalty.                    |        - (induced from highest value of defaultequip)        | yes                                                      |
|        Accuracy        |   Equivalent to 0.1 accuracy in KC, countered by evasion.    | - (induced from highest value of defaultequip and ship type and level) | yes                                                      |
|    Torpedoaccuracy     | Like accuracy but only applies to torpedo (excluding air) attacks. |                            ditto                             | yes                                                      |
|        Evasion         |               Equivalent to 0.1 evasion in KC.               |                            ditto                             | yes                                                      |
|          Los           |      Have stacking penalty (on same type of equipment).      |                            ditto                             | yes                                                      |
|      Concealment       | Decrease the likelihood of enemy targeting this ship. A well-concealed fleet can prevent enemy from firing, countered by los. | ditto (for submarines this is countered not by los value but ASW value instead) | yes                                                      |
|      Firingrange       | A long range and high los may increase the effective battle time. |        - (induced from highest value of defaultequip)        | yes                                                      |
|      Firingspeed       | A high firing speed may increase the shots fired in a given battle time. |                    - (induced from equip)                    | yes                                                      |
|         Speed          | in knots. A higher speed than enemy increases battle time, evasion and los. |                            ditto                             | yes                                                      |
|        Torpedo         |               Equivalent to 0.1 torpedo in KC.               |                            ditto                             | yes                                                      |
|       Airtorpedo       |     Equivalent to 0.1 torpedo in KC but only for planes.     |                              -                               | Only for carrier ships                                   |
|        Bombing         |               Equivalent to 0.1 bombing in KC.               |                              -                               | Only for carrier ships                                   |
|        Antiair         |               Equivalent to 0.1 antiair in KC.               |                            ditto                             | yes                                                      |
|          Asw           |                 Equivalent to 0.1 asw in KC.                 |                            ditto                             | yes                                                      |
|      Interception      |                          Unchanged.                          |                              -                               | Only for land-structure "kanmusu", that is ID 0x???C???? |
|       Antibomber       |                          Unchanged.                          |                              -                               | Only for land-structure "kanmusu", that is ID 0x???C???? |
|        Antiland        | Anti land-based enemy capabilities. Bomber with antiland=0 does not attack them. |                            ditto                             | yes                                                      |
|       Transport        |                   Transport capabilities.                    |                            ditto                             | yes                                                      |
|      Flightrange       |                          Unchanged.                          |                              -                               | no                                                       |
|    FuelConsumption     |                              -                               |            Equivalent to 0.1 of this value in KC             | no                                                       |
|    AmmoConsumption     |                              -                               |            Equivalent to 0.1 of this value in KC             | no                                                       |
