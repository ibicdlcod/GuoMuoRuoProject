# Remodel

[Implemented in Server::doConstruct#remodel]

In this game remodel is much like construction, you just need blueprints of not the base ship but of a later remodel level.

Remodeling usually have a different set of required equipment that still must be provided. However, if the remodel does not advance basic remodel level (determined by first hexadecimal digit of ship id), then the original required equipment of older level will be refunded (without any improvements) (note planes are not eligible for this, as they are not consumed in first place).
